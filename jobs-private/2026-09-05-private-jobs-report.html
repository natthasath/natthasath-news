📌 Executive Summary

⚠️ ข้อจำกัดของข้อมูลสัปดาห์นี้: เครื่องมือ WebFetch ของเซสชันนี้ถูกบล็อกโดย network egress สำหรับทุกโดเมนที่ทดสอบ (LinkedIn, JobsDB, JobThai, Greenhouse, เว็บบริษัทโดยตรง ฯลฯ) จึงไม่สามารถเปิดหน้าประกาศจริงเพื่อยืนยันได้โดยตรง ข้อมูลทั้งหมดด้านล่างมาจาก WebSearch snippet เท่านั้น และมีเพียง 2 ตำแหน่ง (MIC Customs Solutions, PTG Energy) ที่ระบุลิงก์ประกาศเฉพาะเจาะจงได้ ส่วนที่เหลือมีเพียงลิงก์หน้ารวมประกาศของบริษัทบน JobsDB เนื่องจากค้นหาไม่พบ URL ประกาศรายตำแหน่งโดยตรง

ระหว่างการค้นหา พบประกาศ 2 รายการ (Finema Co., Ltd. และ FlowAccount Co., Ltd. — ตำแหน่ง Software Engineer เดียวกัน เงินเดือน 50,000–75,000 บาท) ที่มีข้อความคำอธิบายซ้ำกันทุกคำระหว่างสองบริษัท ซึ่งไม่สามารถยืนยันได้ว่าเป็นประกาศจริงของบริษัทใด จึงตัดออกจากรายการหลักตามหลักการ "ห้ามสร้างข้อมูลขึ้นเอง" (ดูรายละเอียดในหมวด Watch List) นอกจากนี้ยังพบตำแหน่ง SRE ที่ SCB DataX ซึ่งข้อมูลอายุประกาศบ่งชี้ว่าใกล้หมดอายุ จึงไม่นำมาแสดงเช่นกัน เนื่องจากไม่สามารถยืนยันว่ายังเปิดรับสมัครอยู่จริง

เนื่องจากไม่สามารถเข้าถึง Tier 1 โดยตรง (Company Career Page/LinkedIn) เพื่อยืนยันซ้ำ ตำแหน่งส่วนใหญ่ในรายงานนี้จึงมีแหล่งอ้างอิงเพียงแหล่งเดียว (JobsDB ผ่าน WebSearch) ไม่ครบตามเกณฑ์ Cross Validation ที่ต้องการอย่างน้อย 2 แหล่ง — ผู้อ่านควรตรวจสอบซ้ำก่อนสมัครหรืออ้างอิงตัวเลขเงินเดือน

สัปดาห์นี้พบตำแหน่งงานภาคเอกชนด้าน IT ในประเทศไทยที่ผ่านเกณฑ์การตรวจสอบเบื้องต้น (เงินเดือนเปิดเผย ≥ 45,000 บาท/เดือน, วุฒิปริญญาตรีขึ้นไปหรือไม่ระบุกีดกัน, ประเภทงาน Full-time/Contract, เป็นบริษัทเอกชน) รวม 8 ตำแหน่ง จาก 7 องค์กร ครอบคลุมช่วงเงินเดือน 50,000–120,000 บาท/เดือน กลุ่มที่โดดเด่นคือสายงาน Enterprise Systems/PM, Security/SOC และ QA ผ่านเอเจนซี่จัดหางาน ส่วนสาย Software Engineer ทั่วไปมีให้เห็นแต่เงินเดือนที่เปิดเผยส่วนใหญ่อยู่ในช่วง 50,000–75,000 บาท ประกาศส่วนใหญ่ของสัปดาห์นี้ไม่ระบุ Tech Stack แบบเจาะจง (ระบุเพียงหมวดกว้าง เช่น "full stack" "cloud") ทำให้การวิเคราะห์ Tech Stack เชิงลึกทำได้จำกัด

📈 Market Trends

  • Salary Trends: จากตัวอย่าง 8 ตำแหน่งที่ยืนยันได้ เงินเดือนกระจุกตัวใน 2 กลุ่ม — กลุ่ม Software Engineer สาย Contract (50,000–75,000 บาท) และกลุ่มตำแหน่งบริหาร/ผู้เชี่ยวชาญเฉพาะทาง เช่น PM/BA และ Security (70,000–120,000 บาท) สะท้อนว่าตำแหน่งที่มีขอบเขตความรับผิดชอบสูงหรือขาดแคลนทักษะเฉพาะยังคงได้ค่าตอบแทนพรีเมียมชัดเจน
  • Hiring Trends: สัปดาห์นี้พบสัดส่วนตำแหน่งแบบ Contract ค่อนข้างสูง (3 จาก 8 ตำแหน่ง) รวมถึงการจ้างผ่านเอเจนซี่จัดหางาน (Learn Bridge) 2 ตำแหน่ง ซึ่งบ่งชี้ว่าบริษัทบางส่วนยังเลือกใช้รูปแบบจ้างงานที่ยืดหยุ่นแทนการจ้างประจำโดยตรง
  • Tech Stack: ข้อมูลจำกัดมาก — ประกาศส่วนใหญ่ไม่ระบุภาษาโปรแกรมมิ่งหรือเฟรมเวิร์กเฉพาะเจาะจง มีเพียง MIC Customs Solutions ที่ระบุ Multi-cloud (AWS/Azure/GCP) ชัดเจน
  • AI: ไม่พบตำแหน่งที่ระบุ AI/ML/LLM/RAG โดยตรงในสัปดาห์นี้ที่ผ่านเกณฑ์เงินเดือนและยืนยันได้
  • Data: ไม่พบตำแหน่ง Data Engineer/Scientist/Analyst ที่ผ่านเกณฑ์และยืนยันได้ในสัปดาห์นี้ (พบตำแหน่งที่เงินเดือนต่ำกว่าเกณฑ์ เช่น Data Engineer ที่ Digithun Worldwide 24,000–35,000 บาท ซึ่งไม่เข้าเกณฑ์รายงานนี้)
  • Cloud: Cloud Platform Engineer ที่ MIC Customs Solutions เป็นตัวอย่างเดียวที่ชัดเจน เงินเดือน 55,000–80,000 บาท พร้อม Hybrid Work
  • DevOps: พบประกาศ DevOps หลายรายการระหว่างการค้นหา แต่ส่วนใหญ่เงินเดือนที่เปิดเผยต่ำกว่าเกณฑ์ 45,000 บาท (เช่น T.N. Incorporation 35,000–50,000, 1Moby 30,000–70,000, Studio Craftsmanship 35,000–60,000) จึงไม่ผ่านเกณฑ์รายงานนี้
  • Cybersecurity: ตำแหน่ง SOC/Security ที่ B.Grimm Power (70,000–100,000 บาท) เป็นสัญญาณว่าองค์กรนอกกลุ่มเทคโนโลยีโดยตรง (เช่น พลังงาน) ก็เริ่มลงทุนด้าน Security Operations มากขึ้น
  • Remote Work: มีเพียง 1 ใน 8 ตำแหน่งที่ระบุ Remote ชัดเจน (ผ่านเอเจนซี่) สะท้อนว่าตำแหน่งเงินเดือนสูงส่วนใหญ่ในสัปดาห์นี้ยังเป็น On-site/Hybrid หรือไม่ระบุรูปแบบชัดเจน
  • Hybrid Work: 2 ตำแหน่ง (MIC Customs Solutions, Quantium Technology) ระบุ Hybrid ชัดเจน
  • Startup Hiring: ไม่พบประกาศจาก Startup ขนาดเล็กที่เปิดเผยเงินเดือนผ่านเกณฑ์ในสัปดาห์นี้

ภาพรวมตลาดงาน IT ภาคเอกชนของไทยสัปดาห์นี้ยังคงมีตำแหน่งเงินเดือนสูงกระจุกตัวอยู่ในสายงานบริหารโครงการและความปลอดภัยไซเบอร์ที่บริษัทองค์กรขนาดใหญ่ (Enterprise) มากกว่าสาย Software Engineering ทั่วไป ขณะที่การเปิดเผยเงินเดือนในประกาศงานยังเป็นข้อจำกัดใหญ่ที่สุดของการทำรายงานนี้ — ประกาศจำนวนมากที่พบระหว่างการค้นหา (โดยเฉพาะจาก LinkedIn และ Greenhouse ของบริษัทเทคโนโลยีชื่อดัง เช่น Agoda, Sertis, Capco, EarnIn) ไม่ระบุตัวเลขเงินเดือนเลย ทำให้ไม่สามารถนำมาประเมินตามเกณฑ์รายงานนี้ได้ แม้ตำแหน่งเหล่านั้นอาจตรงตามคุณสมบัติอื่นทั้งหมดก็ตาม

สัปดาห์ถัดไปควรติดตามเป็นพิเศษ: (1) ตรวจสอบซ้ำว่าตำแหน่ง SRE ที่ SCB DataX ยังเปิดรับอยู่หรือไม่ (2) ยืนยันแหล่งที่มาที่แท้จริงของประกาศ Software Engineer เงินเดือน 50,000–75,000 บาท ที่มีข้อความซ้ำกันระหว่าง Finema และ FlowAccount (3) หากเข้าถึง WebFetch/Tier 1 ได้ตามปกติในสัปดาห์หน้า ควรยืนยันซ้ำทุกตำแหน่งในรายงานนี้โดยเฉพาะรายการที่มีเพียงลิงก์หน้ารวมประกาศบริษัทแทนลิงก์ประกาศเฉพาะเจาะจง
