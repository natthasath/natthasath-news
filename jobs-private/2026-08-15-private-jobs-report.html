📌 Executive Summary

⚠️ ข้อจำกัดของข้อมูลสัปดาห์นี้: เครื่องมือเปิดหน้าเว็บโดยตรง (WebFetch) ถูกบล็อกโดยนโยบาย network egress ของสภาพแวดล้อมนี้สำหรับ ทุกโดเมนที่ลองเข้าถึง (LinkedIn, Greenhouse, JobsDB, Indeed, Company Career Pages) — เป็นการบล็อกระดับสภาพแวดล้อม ไม่ใช่การบล็อกบอทเฉพาะเว็บไซต์ จึงได้เปลี่ยนไปใช้ WebSearch พร้อม site: query ตามขั้นตอน Network Access Resilience แทน ซึ่งให้ผลเป็น search snippet เท่านั้น ไม่ใช่หน้าประกาศงานฉบับเต็ม (UNCERTAIN: WebFetch — ทุกโดเมน Tier 1–2, บล็อกระดับสภาพแวดล้อม ไม่สามารถยืนยันผ่านการเปิดหน้าเว็บโดยตรงได้ทั้งสัปดาห์)

ผลคือพบตำแหน่งงานที่ ยืนยันตัวเลขเงินเดือนได้ตรงตามเกณฑ์ (≥45,000 บาท/เดือน) เพียง 3 ตำแหน่งจาก 3 บริษัท ทั้งหมดเป็นระดับความเชื่อมั่น "Medium" (ตัวเลขเงินเดือนมาจาก search snippet ของ job board ไม่ได้ยืนยันจากการเปิดหน้าประกาศโดยตรง และไม่ผ่านเกณฑ์ Cross Validation แบบ 2 แหล่งอิสระเต็มรูปแบบ) นอกจากนี้ยังพบตำแหน่งงานที่เปิดรับจริงและมีลิงก์สมัครที่ใช้งานได้อีกกว่า 20 ตำแหน่งจากบริษัทที่มีชื่อเสียง (เช่น Agoda, Sertis, KTC, Krungsri Nimble, SCB TechX, Ascend Money/TrueMoney, Deloitte) แต่ไม่พบตัวเลขเงินเดือนที่ยืนยันได้ในเนื้อหาที่เข้าถึงได้ — ประกาศเหล่านี้จึงไม่นำมาแสดงในตารางหลักตามเกณฑ์ Validation Rules แต่รวบรวมไว้ในหมวด Watch List เพื่อการติดตามด้วยตนเอง

สัปดาห์นี้มีตำแหน่งงานภาคเอกชนด้าน IT ในประเทศไทยที่ยืนยันได้ครบตามเกณฑ์ขั้นต่ำ 3 ตำแหน่ง ได้แก่ AEM Project Solution Architect ที่ NSEARCH IT Services (100,000–150,000 บาท/เดือน), DevOps Engineer ที่ Krungthai Bank (60,000–90,000 บาท/เดือน) และ Azure Solution Architect ที่ Metro Systems Corporation (50,000–70,000 บาท/เดือน) ทั้งหมดอยู่ในกลุ่มงานที่ปรึกษา/ระบบสารสนเทศองค์กรและธนาคาร สะท้อนแนวโน้มที่สาย Solution Architecture และ Cloud/DevOps ยังคงมีการเปิดรับด้วยเงินเดือนสูงกว่าเกณฑ์ขั้นต่ำของรายงานนี้อย่างชัดเจน แม้จำนวนตำแหน่งที่ยืนยันได้จะน้อยกว่าจำนวนตำแหน่งเปิดรับจริงในตลาดมาก เนื่องจากข้อจำกัดด้านการเข้าถึงข้อมูลของระบบในสัปดาห์นี้

📈 Market Trends

ข้อมูลด้านล่างประกอบด้วยสัญญาณจากตำแหน่งที่ยืนยันเงินเดือนได้ (3 ตำแหน่ง) และสถิติตลาดเชิงเปรียบเทียบจากแหล่งอ้างอิงสาธารณะ ณ เดือนสิงหาคม 2026 ใช้เพื่อประกอบการติดตามแนวโน้มเท่านั้น:

  • Cloud: ตำแหน่ง Solution Architect สาย Cloud (Azure) ยังเปิดรับด้วยเงินเดือน ฿50,000–150,000/เดือน ที่บริษัท System Integrator ของไทย และพบตำแหน่ง Cloud/DevOps Engineer เปิดรับเพิ่มเติมที่ Krungsri Nimble, G-Able, MFEC, Huawei Thailand แม้ไม่พบตัวเลขเงินเดือนที่ยืนยันได้
  • DevOps: Krungthai Bank เปิดรับ DevOps Engineer ที่ ฿60,000–90,000/เดือน สอดคล้องกับแนวโน้มที่ธนาคารไทยขนาดใหญ่ (KTC, Bangkok Bank, SCB TechX) ยังคงเปิดรับสาย DevOps/Cloud อย่างต่อเนื่อง
  • AI / Data: ไม่พบตำแหน่งที่ยืนยันเงินเดือนได้ในสัปดาห์นี้ แต่พบตำแหน่งเปิดรับจริงในสาย AI/ML/Data ที่ True Corporation, BJAK, Deloitte, Sertis, KTC (Data Engineer), Ascend Money/TrueMoney (Data Scientist/ML Engineer) โดยใช้ Tech Stack เช่น Python, Airflow, BigQuery
  • Cybersecurity: พบตำแหน่ง SOC Analyst L1 เปิดรับที่ Accenture Thailand และ Penetration Tester/IT Audit ที่ Deloitte Thailand แต่ทั้งสองไม่ระบุเงินเดือน (ระบุเป็น "negotiable")
  • Remote Work: ไม่พบตำแหน่งที่ยืนยันเงินเดือนได้และเป็น Remote เต็มรูปแบบในสัปดาห์นี้ — ตำแหน่งที่ยืนยันได้ทั้ง 2 ที่มีข้อมูล Work Arrangement เป็น Hybrid
  • Salary Trends (สถิติตลาดทั่วไป ไม่ใช่ประกาศรายตำแหน่ง): Jobsdb ระบุเงินเดือนเฉลี่ยของ Software Engineer ในไทยอยู่ที่ประมาณ ฿37,000–62,000/เดือน (สิงหาคม 2026) ขณะที่ Glassdoor ระบุค่ากลาง Software Engineer ในกรุงเทพฯ ที่ประมาณ ฿57,792/ปี ถึง 92,500/ปี ในช่วง 25th–75th percentile และ Senior Software Engineer เฉลี่ยประมาณ ฿116,667/ปี (แหล่ง: Jobsdb, Glassdoor)

สัปดาห์นี้ตลาดตำแหน่ง IT ภาคเอกชนในไทยยังคงมีการเปิดรับต่อเนื่องในสาย Solution Architecture (Cloud/Enterprise), DevOps และ Cloud Engineering โดยเฉพาะที่บริษัท System Integrator และธนาคารรายใหญ่ ซึ่งเป็นกลุ่มเดียวที่สามารถยืนยันตัวเลขเงินเดือนได้ครบตามเกณฑ์ในสัปดาห์นี้ อย่างไรก็ตาม ข้อมูลจากหมวด Watch List ชี้ว่าตลาดยังมีการเปิดรับกว้างกว่านี้มากในสาย Software Engineering, Data/AI, Cybersecurity และ FinTech ที่บริษัทเทคชั้นนำ (Agoda, Sertis, KTC, Krungsri Nimble, SCB TechX, Ascend Money) เพียงแต่ไม่เปิดเผยตัวเลขเงินเดือนต่อสาธารณะ ซึ่งเป็นแนวปฏิบัติทั่วไปของตลาดแรงงานไทย สิ่งที่ควรติดตามในสัปดาห์ถัดไปคือ (1) ตรวจสอบว่าเครื่องมือ WebFetch ของระบบกลับมาเข้าถึงโดเมน Tier 1–2 ได้ตามปกติหรือไม่ เพื่อให้สามารถเปิดหน้าประกาศงานฉบับเต็มและยืนยันเงินเดือนของตำแหน่งใน Watch List ได้ และ (2) ติดตามตำแหน่งใหม่ที่อาจเปิดรับเพิ่มเติมจากบริษัทในกลุ่ม Watch List ซึ่งมีประวัติเปิดรับสาย Engineering อย่างต่อเนื่อง
