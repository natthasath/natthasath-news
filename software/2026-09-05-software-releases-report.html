Week: 36 Period: August 29 – September 5, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (29 ส.ค. – 5 ก.ย. 2569) ประเด็นเด่นด้านความปลอดภัยคือช่องโหว่ Zero-day ระดับ V8 ใน Google Chrome (CVE-2026-85046) ที่ถูกใช้โจมตีจริงและถูกเพิ่มเข้า CISA Known Exploited Vulnerabilities Catalog เมื่อ 4 ก.ย. รวมถึงช่องโหว่ระดับวิกฤติ 2 รายการใน VMware Workstation/Fusion (VMSA-2026-0007) ที่เปิดทางให้ผู้โจมตีหลบหนีออกจาก Virtual Machine ไปยัง Host ได้โดยไม่มี Workaround

นอกจากนี้ยังมีแพตช์ความปลอดภัยจาก Mozilla Firefox ESR, Ubuntu (เคอร์เนลและแพ็กเกจอื่น ๆ), Debian และ Elasticsearch ฝั่ง DevOps/Developer Tools มีการอัปเดตตามรอบปกติของ Docker Engine, Go, Terraform, GitHub Actions และ Visual Studio Code สัปดาห์นี้ไม่พบการเปิดตัว Major Release หรือ Framework Release ใหม่ที่ตรวจสอบแหล่งที่มาได้ตามเกณฑ์ที่กำหนด

ประเด็นสำคัญ: ทีมงานควรเร่งอัปเดต Google Chrome และ VMware Workstation/Fusion โดยด่วนเนื่องจากมีความเสี่ยงถูกโจมตีจริงและ/หรือความรุนแรงระดับ Critical
