💻 Weekly Software Releases Report

Week: 38 Period: September 13 – 19, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (13–19 ก.ย. 2569) ด้านความปลอดภัยมี Zero-day ที่กำลังถูกใช้โจมตีจริงหลายรายการพร้อมกัน โดยเฉพาะ Cisco ISE/ISE-PIC (CVE-2026-76460, CVSS 10.0, Auth Bypass ไม่ต้องยืนยันตัวตน), Cisco Secure Email Gateway (CVE-2026-76461, CVSS 9.8, SQL Injection นำไปสู่ RCE ระดับ root) และ Issabel Framework ระบบ PBX โอเพนซอร์ส (CVE-2026-89026) ซึ่งทั้งหมดถูก CISA เพิ่มเข้า KEV Catalog แล้ว นอกจากนี้ Linux Kernel ยังมีช่องโหว่ที่ถูกใช้โจมตีจริง 3 รายการ (kTLS, ebtables, AF_ALG) ฝั่ง Ubuntu และ Debian มีการออก Security Advisory จำนวนมากต่อเนื่อง ครอบคลุมทั้ง Kernel หลายสาย, SQLite, python-cryptography, rclone และ Chromium/Firefox/Thunderbird

ด้าน Software Release มี Java/OpenJDK 27 ออกเป็น Major Release (GA) พร้อม G1 เป็น Garbage Collector ค่าเริ่มต้นทั่วทุกสภาพแวดล้อมและรองรับ Post-Quantum Key Exchange สำหรับ TLS 1.3 เป็นครั้งแรก ฝั่ง Database มี MariaDB 13.0.2 และ Elasticsearch 9.5.4 ออกเวอร์ชันใหม่ ฝั่ง DevOps มีความเคลื่อนไหวหนาแน่นทั้ง Docker Engine/Desktop, Jenkins, Terraform, ArgoCD และ containerd 2.4.0 ซึ่งมี Breaking Change จากการถอดตัวเลือก Config ที่เลิกใช้แล้ว ฝั่ง Framework ยังไม่มี Major Release ใหม่ แต่ Vue 3.6, Angular 22.2 และ ArgoCD 3.6 ต่างเข้าสู่สถานะ Release Candidate ที่ควรเริ่มทดสอบ

ประเด็นสำคัญ: ทีมงานที่ดูแล Cisco ISE, Cisco Secure Email Gateway และระบบที่ใช้ Issabel Framework ควรอัปเดตโดยด่วนที่สุดเนื่องจากมีการโจมตีจริงแล้ว รวมถึงเร่งอัปเดต Linux Kernel ตาม CVE ที่ถูกเพิ่มใน CISA KEV Catalog ภายในกำหนดเวลา
