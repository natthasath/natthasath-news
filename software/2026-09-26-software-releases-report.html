Week: 39 Period: September 20 – 26, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (20–26 ก.ย. 2569) เป็นสัปดาห์ที่หนักด้านความปลอดภัยระดับ Critical ที่กำลังถูกโจมตีจริงพร้อมกันหลายรายการ ได้แก่ Arista VeloCloud Orchestrator (CVE-2026-93952, CVSS 10.0), Check Point Security Gateway/Spark Firewall (CVE-2026-85102, CVSS 9.8) และ Check Point Management Web Service (CVE-2026-93616, CVSS 9.8), F5 BIG-IP APM (CVE-2026-94127, Zero-day, CVSS 9.8) และ Zyxel GS1900 Switch (CVE-2026-7273, CVSS 8.8) ที่มีรายงานว่า Switch ถูกยึดควบคุมแล้วเกือบ 1,000 เครื่อง นอกจากนี้ GitLab ยังออก Critical Patch (19.4.1/19.3.3/19.2.7) แก้ RCE คะแนน CVSS 9.9 สองรายการใน CI/CD Regex Parser และ AlmaLinux ออกแพตช์ FreeIPA/IdM ระดับ Critical (CVSS 9.8) เช่นกัน

ด้าน Software Release สัปดาห์นี้ไม่มี Major Release ใหม่ แต่มีความเคลื่อนไหวหนาแน่นในหลายสาย: PostgreSQL 19 Beta 4 เตรียมเข้าสู่ RC, PHP ออกแพตช์ประสานงาน 4 เวอร์ชันพร้อมกัน (8.5.11/8.4.26/8.3.35/8.2.34) ควบคู่กับ Release Candidate ของ PHP 8.6 ที่มีความไม่ตรงกันของชื่อ Tag ระหว่างแหล่งข้อมูล, Angular ออก 22.2.0 (Minor) พร้อม `@boundary` Block ใหม่, Kubernetes และ containerd ออกแพตช์ประสานงานหลายสาขาพร้อมกัน และ GitHub Actions ประกาศถอด Node.js 20 ออกจาก Runner อย่างเป็นทางการซึ่งถือเป็น Breaking Change สำหรับ Custom JavaScript Actions

ประเด็นสำคัญ: ทีมงานที่ดูแล Arista VeloCloud, Check Point Security Gateway/Management, F5 BIG-IP APM (เมื่อกำหนดค่าเป็น OAuth Authorization Server) และ Zyxel GS1900 Switch ควรอัปเดต/แพตช์โดยด่วนที่สุดเนื่องจากมีการโจมตีจริงแล้ว ส่วนทีมที่ใช้ GitLab CI/CD และ AlmaLinux/FreeIPA ควรอัปเกรดเชิงรุกก่อนถูกใช้โจมตี และทีม CI/CD ที่มี Custom GitHub Action ควรตรวจสอบว่า Action รองรับ Node.js 24 แล้วก่อนถูกตัดการทำงาน
