💻 Weekly Software Releases Report

Week: 46 Period: November 8 – 14, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (8–14 พ.ย. 2569) เป็นสัปดาห์ที่มีความเคลื่อนไหวด้านความปลอดภัยหนาแน่นที่สุดในรอบหลายสัปดาห์ ตรงกับ Microsoft Patch Tuesday ประจำเดือนพฤศจิกายน 2569 (10 พ.ย. 2569) ที่แก้ไขช่องโหว่รวมประมาณ 1,090 รายการ (63 Critical ตามแหล่งข่าวส่วนใหญ่ ตัวเลขแตกต่างกันเล็กน้อยระหว่างแหล่ง) โดยมี Zero-day ที่ถูกโจมตีจริงแล้วรวมอยู่ด้วยคือ CVE-2026-124194 ในไมโครซอฟท์ Outlook ซึ่งขโมยค่า NTLMv2 Hash ของผู้ใช้ และถูกเพิ่มเข้า CISA Known Exploited Vulnerabilities Catalog ทันที

นอกจากนี้ยังมี Critical CVE อีกหลายรายการที่ควรเร่งแพตช์ ได้แก่ Apache HTTP Server 2.4.71 (CVE-2026-119618, Race Condition ใน mod_http2 ที่อาจนำไปสู่ Remote Code Execution), GitLab 19.5.4 / 19.4.6 / 19.3.8 (CVE-2026-105437, Heap Buffer Overflow ใน Git ที่ฝังมากับ GitLab ผ่าน Gitaly) และ Red Hat edk2 Firmware (CVE-2026-97631, Pre-boot Remote Code Execution ผ่าน RHSA-2026:96240)

ด้าน End of Life มีเหตุการณ์สำคัญชนกันในวันเดียว (10 พ.ย. 2569) ถึง 3 รายการ ได้แก่ .NET 8 / .NET 9, PowerShell 7.4 (LTS) / 7.5 และ Windows 11 23H2 (Enterprise/Education) ที่หมดการสนับสนุนพร้อมกัน ส่วน Red Hat เปิดตัว RHEL 10.3 / RHEL 9.9 (Minor Release) พร้อมฟีเจอร์ AI-assisted Troubleshooting เมื่อ 11 พ.ย. 2569 และ PostgreSQL ออก 19 RC2 พร้อมอัปเดต Non-19 ทุกสาย และประกาศ PostgreSQL 14 สิ้นสุดการสนับสนุน ในวันเดียวกัน (12 พ.ย. 2569)

ด้าน Programming Languages มีเพียง Node.js 26.13.1 "Lithium" (LTS) ที่ออก Security Release แก้ไข 16 CVE เมื่อ 11 พ.ย. 2569 ส่วน Python, Go, Rust, Java และ Frameworks หลัก (React, Vue, Angular, Django, Laravel, FastAPI, Spring Boot) ไม่พบ Release ใหม่ที่ยืนยันได้ในช่วงเวลานี้

ประเด็นสำคัญ: ทีมที่ใช้ Outlook/Microsoft 365 Apps ควรเร่งติดตั้งแพตช์เดือน พ.ย. 2569 ทันทีเนื่องจากมี Zero-day ที่ถูกโจมตีจริง ทีมที่ใช้ Apache HTTP Server 2.4.55–2.4.70, GitLab รุ่นก่อน 19.3.8/19.4.6/19.5.4 และ RHEL ที่มี edk2 เวอร์ชันเก่าควรอัปเดตโดยเร็ว ทีมที่ยังใช้ .NET 8/9, PowerShell 7.4/7.5 หรือ Windows 11 23H2 รุ่น Enterprise/Education ควรวางแผนอัปเกรดทันทีเนื่องจากไม่ได้รับแพตช์ความปลอดภัยอีกต่อไป
