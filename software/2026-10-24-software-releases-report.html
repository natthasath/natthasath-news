💻 Weekly Software Releases Report

Week: 43 Period: October 18 – 24, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (18–24 ต.ค. 2569) เรื่องใหญ่ที่สุดคือเหตุการณ์กุญแจเข้ารหัสของ Intermediate CA ของ eMudhra/emSign จำนวน 8 ชุดถูกเปิดเผยว่าหลุดรั่ว (CVE-2026-111943) ซึ่งส่งผลกระทบเป็นลูกโซ่ให้ Go ออกแพตช์ฉุกเฉิน (1.27.3/1.26.10) บล็อกความน่าเชื่อถือของ CA เหล่านั้นในระดับ Toolchain ตามด้วย Docker Engine, Docker Compose, Terraform และ Argo CD ที่ต้องอัปเดต Go Runtime ตามเพื่อปิดช่องโหว่เดียวกัน ขณะที่ Node.js และ Python ก็ออก Security Release แยกกันในวันเดียวกัน (21 ต.ค.) เพื่อตัดความเชื่อถือ CA ชุดนี้เช่นกัน พร้อมแก้ไขช่องโหว่อื่นรวมกันอีกหลายรายการ (Node.js 10 CVE รวม Brotli Decoder Out-of-bounds Write ที่เสี่ยง RCE)

เรื่องใหญ่คู่กันคือ PHP ออกแพตช์ฉุกเฉินนอกรอบที่ถูกเรียกว่า "PHP2Shell" แก้ไขช่องโหว่ Critical 2 รายการ (CVE-2026-109618, CVE-2026-109619, CVSS v4.0 9.2) ที่ไม่ต้องยืนยันตัวตนก็โจมตีได้บนเกือบทุกรูปแบบการรันเว็บด้วย PHP นอกจากนี้ยังมีรายงาน (ยังไม่ยืนยันสมบูรณ์) ว่า GitLab ออกแพตช์ฉุกเฉินแก้ไขช่องโหว่ Critical CVSS เต็ม 10.0 อีกครั้ง (CVE-2026-110264) แต่ไม่สามารถยืนยันหมายเลขเวอร์ชันที่แก้ไขจริงจาก docs.gitlab.com ได้โดยตรงในรอบตรวจสอบนี้ ด้าน Oracle ออก Critical Patch Update ประจำเดือน ต.ค. (รวมกับ MySQL 26.10/9.7.4/8.4.13) และ Ubuntu ออกชุด USN 10 รายการครอบคลุม zlib, OpenVPN, Tornado, c-ares, poppler, Ghostscript และการถอนความเชื่อถือ Root CA ที่ถูกเพิกถอน 2 ชุดผ่าน NSS

ด้าน Software Release ทั่วไป: Terraform v1.17.0 เข้าสู่ GA ของ Policy Feature พร้อม Breaking Change ในฟังก์ชัน log/pow, Vue ออก RC ตัวที่ 13 ของสาย 3.6, Spring Boot ออก RC1 ของสาย 4.2 พร้อมแพตช์ 4.1.2/4.0.9, FastAPI ออกต่อเนื่อง 10 เวอร์ชันในรอบสัปดาห์เดียว (รวม Breaking Change ใน 0.160.0), Traefik แก้ไขช่องโหว่ High Severity ของ ForwardAuth ที่หลุดข้อมูลยืนยันตัว NTLM/Negotiate ข้าม Client, Google Cloud SDK ออกเวอร์ชัน 590.0.0 พร้อม Breaking Change (ถอด Component บางส่วน) และ GitHub CLI/Actions Runner/Gradle/Composer/pip ต่างออกอัปเดตของตนเองในสัปดาห์นี้

ประเด็นสำคัญ: ทีมที่ใช้งาน PHP ในรูปแบบใดก็ตาม (PHP-FPM, mod_php, php-cgi, FrankenPHP, LiteSpeed) ควรอัปเกรดเป็น 8.5.12/8.4.27/8.3.36/8.2.35 โดยเร็วที่สุดเนื่องจากมีรายงานความพยายามโจมตีแล้วก่อนมีแพตช์ครบทุกฝ่าย ทีมที่ Build Binary ด้วย Go, ใช้ Docker/Docker Compose, Terraform หรือ Argo CD ควร Rebuild/อัปเดตเป็นเวอร์ชันล่าสุดเพื่อตัดความเชื่อถือ CA ที่ถูกเพิกถอน (การอัปเดต OS Root Store เพียงอย่างเดียวไม่เพียงพอ) ทีมที่ใช้ GitLab Self-managed ควรตรวจสอบ Advisory ของ GitLab โดยตรงเนื่องจากข้อมูล CVE-2026-110264 ยังมีความไม่แน่นอนด้านแหล่งที่มา และทีมที่ใช้ Ivanti Connect Secure ควรทราบว่ายังมีช่องโหว่ Privilege Escalation ตัวที่ 3 ในชุดการโจมตีเดิมที่ยังไม่มี CVE และไม่มีแพตช์
