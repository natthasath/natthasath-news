💻 Weekly Software Releases Report

Week: 47 Period: November 15 – 21, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (15–21 พ.ย. 2569) มี Major Release สำคัญถึง 3 รายการชนกัน ได้แก่ PostgreSQL 19.0 (GA, 19 พ.ย.) ที่มาพร้อม Breaking Change สำคัญเรื่อง standard_conforming_strings, PHP 8.6.0 (GA, 19 พ.ย.) และ Spring Boot 4.2.0 (GA, 19 พ.ย.) ด้าน Operating System มี RHEL Rebuild ตามมา 2 ค่าย คือ AlmaLinux 10.3 / 9.9 และ Rocky Linux 10.3 / 9.9 (16 พ.ย.)

ด้านความปลอดภัยถือเป็นสัปดาห์ที่ตึงเครียด โดยเฉพาะ nginx 1.30.7 / 1.31.9 (18 พ.ย.) ที่แก้ไข 10 CVE รวมชุดช่องโหว่ที่เรียกว่า "nginx2root" — 5 รายการเป็น Unauthenticated RCE ผ่าน HTTP/2 ที่ยังไม่มีรายงานการโจมตีจริงแต่มีความรุนแรงสูงมาก ควรเร่งอัปเกรดทันที เช่นเดียวกับ VMware VMSA-2026-0009 (19 พ.ย.) ที่มี CVE-2026-123890 Authentication Bypass ใน VMware Directory Service (CVSS 9.8, ไม่มี Workaround) และ CISA KEV Catalog เพิ่มช่องโหว่ที่ถูกโจมตีจริงแล้ว 4 รายการ (18 พ.ย.) ครอบคลุม Apache Axis 1.x, Vanderbilt REDCap, Synology DSM และ BerriAI LiteLLM โดยมีกำหนดแพตช์สำหรับหน่วยงานรัฐบาลกลางสหรัฐฯ ภายใน 21 พ.ย. และ 2 ธ.ค. 2569

ด้าน Java มี JDK 25.0.5.1 (17 พ.ย.) แก้ไขช่องโหว่ที่ถูกเรียกว่า "Java4Shell" (CVE-2026-114938) ซึ่งมีความเสี่ยง RCE แบบไม่ต้องยืนยันตัวตนใน OpenJDK 17/21/25 สาย ด้าน DevOps/CI-CD มี Minor/Patch Release เรียงกันหลายรายการ ได้แก่ Docker Engine 29.10.0 (16 พ.ย., มี Breaking Change เรื่อง insecure-registries), Jenkins 2.591 (17 พ.ย.), ArgoCD v3.6.2 (18 พ.ย., ผูกกับ CVE-2026-77299 ผ่าน Dependency), Pulumi v3.277.0 (18 พ.ย.) และ GitLab 19.6 (ประมาณ 19–20 พ.ย., ยังไม่สามารถยืนยันวันที่แน่ชัดจาก docs.gitlab.com โดยตรง)

ประเด็นสำคัญ: ทีมที่ดูแล nginx ทุกเวอร์ชันก่อน 1.31.9/1.30.7 ควรเร่งอัปเกรดทันทีเนื่องจากมีช่องโหว่ RCE ระดับ Critical หลายรายการ ทีมที่ใช้ VMware vCenter/SDDC Manager ควรตรวจสอบ VMSA-2026-0009 และแพตช์ CVE-2026-123890 โดยเร็วเนื่องจากไม่มี Workaround ทีมที่ใช้ Apache Axis 1.x (EOL แล้ว), Synology DSM, Vanderbilt REDCap หรือ BerriAI LiteLLM ควรตรวจสอบ CISA KEV และดำเนินการตามกำหนดเวลา ส่วนทีมที่กำลังวางแผนอัปเกรด PostgreSQL เป็น 19 ควรอ่าน Migration Guide เรื่อง standard_conforming_strings อย่างละเอียดก่อนอัปเกรด
