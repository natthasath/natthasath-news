Weekly Digest — Week 34, 2026

💻 Weekly Software Releases Report — Week 34

Date: 23 Aug 2026 ช่วงเวลา: 16–23 Aug 2026 (ICT) Category: Software Source: Claude Code Routine

📌 Executive Summary

สัปดาห์นี้เป็นสัปดาห์ที่หนักด้าน Security มากกว่าฝั่ง Feature Release — ประเด็นใหญ่ที่สุดคือ Cisco ออก Security Hardening Release สำหรับ Crosswork และ Secure Workload พร้อมกัน รวม 9 CVE โดย 5 รายการได้คะแนน CVSS เต็ม 10.0 (Critical) เมื่อ 19 Aug 2026 ตามมาด้วยช่องโหว่ Critical ใน Traefik digestAuth middleware (GHSA-5w68-77r2-r64c) ที่ผู้โจมตีไม่ต้องยืนยันตัวตนก็สามารถ Bypass การ Authentication ได้ แก้ไขแล้วใน v2.11.55/v3.7.11

ด้าน VMware มีความเคลื่อนไหวสำคัญคือ CISA เพิ่ม CVE-2026-59310 (Directory Traversal ใน vCenter Syslog ที่นำไปสู่ Remote Code Execution) เข้าสู่ Known Exploited Vulnerabilities (KEV) Catalog เมื่อ 18 Aug 2026 ยืนยันว่าช่องโหว่นี้ถูกโจมตีจริงในวงกว้าง (แม้ VMSA-2026-0006 ต้นทางจะประกาศไปตั้งแต่ 29 Jul 2026) องค์กรที่ยังไม่แพตช์ vCenter ควรดำเนินการโดยด่วน

Ubuntu และ Debian ออก Security Patch ต่อเนื่องตลอดสัปดาห์ — Ubuntu Kernel (USN-8643-1) สำหรับ 24.04/22.04 LTS เมื่อ 18 Aug และ Debian ออก DSA รวม 5 ฉบับ ครอบคลุม gst-plugins-bad1.0, libnet-dns-perl, OpenJDK 25, Thunderbird และ zfs-linux ระหว่าง 21–23 Aug 2026 ส่วน Redis ออก Security Release (8.10.1 / 7.4.11) เมื่อ 17 Aug 2026 แก้ไข CVE-2026-62356 (Heap Out-of-Bounds Write ใน CMSketch) และช่องโหว่ Memory-Safety อื่นที่บางรายการได้คะแนน CVSS สูงถึง 7.7

ฝั่ง Feature Release มี Go 1.27 GA (19 Aug) พร้อม Generic Methods และ encoding/json v2 เป็นค่าเริ่มต้น, Spring Boot ออกพร้อมกันสามสาย (4.0.8 / 4.1.1 / 4.2.0-M1), GitLab 19.3, Elasticsearch 9.5.2 และ Pulumi AWS Provider v7.43.0 — ทั้งหมดออกในวันเดียวกันคือ 20 Aug 2026

ไม่พบประกาศ End of Life ใหม่ที่ยืนยันได้จากแหล่งข้อมูลทางการในช่วงสัปดาห์นี้ สิ่งที่ต้องจับตาต่อคือ Kubernetes v1.37 "Garhwal" ที่ยังอยู่ระหว่าง Release Candidate และคาดว่าจะ GA ในวันที่ 26 Aug 2026 (นอกช่วงรายงานนี้)
