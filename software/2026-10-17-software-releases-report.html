💻 Weekly Software Releases Report

Week: 42 Period: October 11 – 17, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (11–17 ต.ค. 2569) เป็นสัปดาห์ที่มีประเด็นความปลอดภัยหนาแน่นที่สุดในรอบหลายเดือน นำโดย GitLab ที่ออกแพตช์ฉุกเฉินแก้ไขช่องโหว่ระดับ Critical CVSS เต็ม 10.0 (CVE-2026-97229) ใน CI/CD Regular Expression Compiler ซึ่งผู้โจมตีไม่ต้องยืนยันตัวตนสามารถรันโค้ดบนเซิร์ฟเวอร์ได้ (เวอร์ชันแก้ไข 19.4.2/19.3.5/19.2.8 เมื่อ 12 ต.ค.) ตามด้วยการออก GitLab 19.5 ตามรอบปกติเมื่อ 15 ต.ค. ขณะเดียวกัน Ivanti Connect Secure พบช่องโหว่ Zero-day CVE-2026-104935 (CVSS 8.6) ที่ถูกโจมตีจริงก่อนมีประกาศ และถูกเพิ่มเข้า CISA KEV Catalog เมื่อ 13 ต.ค. และ Microsoft ออก Patch Tuesday เดือน ต.ค. 2569 ครั้งใหญ่ที่สุดเป็นประวัติการณ์กว่า 1,400 CVE (ครั้งแรกที่แตะระดับ 4 หลัก) รวมถึงช่องโหว่ Zero-day ที่ถูกโจมตีจริง CVE-2026-96951 ใน Windows Shell (ข้ามการป้องกัน Mark of the Web)

ด้าน Software Release ทั่วไป: Node.js ออกรุ่น LTS ใหม่ 24.22.0 "Krypton" และรุ่น Current 26.12.0 พร้อมกันเมื่อ 14 ต.ค., Docker Engine ออกแพตช์ v29.9.1 เมื่อ 14 ต.ค., PostgreSQL ออก 19 RC1 ตามกำหนดเมื่อ 15 ต.ค. แต่ทีมพัฒนาเลื่อนกำหนด GA จากเดิม 29 ต.ค. ออกไปเป็น 19 พ.ย. 2569 พร้อมเพิ่ม RC2 อีกรอบในวันที่ 12 พ.ย. และ Ubuntu ออกชุด USN ขนาดใหญ่ (14–15 ต.ค.) ครอบคลุม RabbitMQ, OpenSSH, curl, Apache HTTP Server, BIND, Go, U-Boot และ urllib3

ประเด็นสำคัญ: ทีมที่ใช้งาน GitLab Self-managed ทุกเวอร์ชัน 19.2–19.4 ควรอัปเกรดเป็น 19.4.2/19.3.5/19.2.8 โดยเร่งด่วนที่สุด เนื่องจากเป็นช่องโหว่ CVSS สูงสุดและไม่ต้องยืนยันตัวตน ทีมที่ใช้ Ivanti Connect Secure ควรตรวจสอบสัญญาณการโจมตีและอัปเดตทันทีตามกำหนด CISA KEV (16 ต.ค. ซึ่งผ่านไปแล้ว) และ Windows Server 2022 ได้เข้าสู่ End of Mainstream Support แล้วตั้งแต่ 13 ต.ค. 2569 (เข้าสู่ Extended Support ถึงปี 2574) ทีมที่ยังใช้งานควรวางแผนย้ายไปยัง Windows Server 2025 หรือตรวจสอบเงื่อนไข Extended Support ให้ครบถ้วน
