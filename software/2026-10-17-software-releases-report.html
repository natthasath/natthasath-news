💻 Weekly Software Releases Report

Week: 42 Period: October 11 – 17, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (11–17 ต.ค. 2569) เป็นสัปดาห์ที่มีประเด็นความปลอดภัยหนาแน่นที่สุดในรอบหลายเดือน นำโดย GitLab ที่ออกแพตช์ฉุกเฉินแก้ไขช่องโหว่ระดับ Critical CVSS เต็ม 10.0 (CVE-2026-97229) ใน CI/CD Regular Expression Compiler ที่ไม่ต้องยืนยันตัวตนก็สามารถรันโค้ดบนเซิร์ฟเวอร์ได้ (เวอร์ชันแก้ไข 19.4.2/19.2.8 และ 19.3.4 หรือ 19.3.5 ตามแต่แหล่งข่าว — ดูหมายเหตุความขัดแย้งของข้อมูลในหัวข้อ Security & CVE) ตามด้วย GitLab 19.5 ที่ออกตามรอบปกติเมื่อ 15 ต.ค. ขณะเดียวกัน Ivanti Connect Secure พบช่องโหว่ Zero-day CVE-2026-104935 (CVSS 8.6) ที่ถูกโจมตีจริงก่อนมีประกาศและถูกเพิ่มเข้า CISA KEV Catalog เมื่อ 13 ต.ค., Microsoft ออก Patch Tuesday เดือน ต.ค. 2569 ครั้งใหญ่ที่สุดเป็นประวัติการณ์ (ประมาณ 1,407–1,415 CVE ขึ้นกับวิธีนับของแต่ละแหล่ง) รวม Zero-day ที่ถูกโจมตีจริง CVE-2026-96951 ใน Windows Shell และ .NET (8.0/9.0/10.0/11.0 RC2) ออก Security Release แก้ไขรวม 44 ช่องโหว่ และ nginx ออกแพตช์ความปลอดภัยแก้ไข Use-after-free ระดับ High (CVE-2026-97205, CVSS 8.1)

ด้าน Software Release ทั่วไป: Node.js ออกรุ่น Current 26.12.0 และ LTS 24.22.0 "Krypton" พร้อมกันเมื่อ 14 ต.ค., Rust ออกแพตช์ 1.99.1, กลุ่ม Framework มีความเคลื่อนไหวหนาแน่น ได้แก่ React (Patch 4 สาย), Vue (Patch 3.5.44 + RC ตัวที่ 12 ของสาย 3.6), Angular 22.2.3, Laravel Framework v13.37.0 และ FastAPI 0.143.1–0.143.3 ฝั่ง DevOps มี Docker Engine v29.9.1, Jenkins (Weekly 2.586 + RC ของ LTS ถัดไป), ArgoCD (Patch 3 สาย + RC ของ 3.6), Terraform (Patch 1.16.6 + RC2 ของ 1.17.0) และ Ansible Core RC แรกของสาย 2.22 ฝั่งฐานข้อมูล PostgreSQL 19 ออก RC1 ตามกำหนดแต่ประกาศเลื่อน GA จาก 29 ต.ค. ไปเป็น 19 พ.ย. 2569 พร้อมเพิ่ม RC2 วันที่ 12 พ.ย. และ Ubuntu ออกชุด USN ขนาดใหญ่ครอบคลุม OpenSSH, Apache HTTP Server, curl, BIND, RabbitMQ, U-Boot, Go และ Kernel หลายสาย นอกจากนี้ยังพบ Traefik v3.7.15, OpenVAS Scanner 3 เวอร์ชันย่อย, Metasploit Framework 6.5.7, VS Code (สาย 1.141–1.142) และ npm CLI v12.2.1/v11.21.1

ประเด็นสำคัญ: ทีมที่ใช้งาน GitLab Self-managed ทุกเวอร์ชัน 19.2–19.4 ควรอัปเกรดโดยเร่งด่วนที่สุดเนื่องจากเป็นช่องโหว่ CVSS สูงสุดและไม่ต้องยืนยันตัวตน ทีมที่ใช้ Ivanti Connect Secure ควรตรวจสอบสัญญาณการโจมตีและอัปเดตทันที (กำหนด CISA KEV ผ่านไปแล้ว) ทีมที่ใช้ nginx ควรอัปเกรดเป็น 1.31.7/1.30.6 และทีมที่ใช้ .NET 8/9/10 ควรติดตั้งแพตช์ความปลอดภัยของเดือนนี้โดยเร็ว สุดท้าย Windows Server 2012/2012 R2 สิ้นสุดการสนับสนุนอย่างสมบูรณ์แล้วตั้งแต่ 13 ต.ค. 2569 (ไม่มี ESU อีกต่อไป) และ Windows Server 2022 เข้าสู่ Extended Support — ทีมที่ยังใช้งานระบบเหล่านี้ควรวางแผนโยกย้ายหรือตรวจสอบเงื่อนไขการสนับสนุนโดยเร็ว
