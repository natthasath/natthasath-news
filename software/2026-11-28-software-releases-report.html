💻 Weekly Software Releases Report

Week: 48 Period: November 22 – 28, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (22–28 พ.ย. 2569) เป็นสัปดาห์ที่ค่อนข้างเงียบเมื่อเทียบกับสัปดาห์ก่อน ไม่พบ Major Release หรือ Security Release ที่มี CVE ID ยืนยันได้โดยตรงรายใหม่ โดยกิจกรรมส่วนใหญ่กระจุกตัวอยู่ในกลุ่ม DevOps/CI-CD ได้แก่ Docker Engine 29.10.1, Kubernetes v1.37.3/v1.36.7/v1.35.11, Jenkins 2.592 (Weekly) และ 2.580.3 (LTS) รวมถึง Ansible ที่ออก Release Candidate 3 สายพร้อมกัน (22.1rc1/21.7rc1/20.12rc1)

รายการที่น่าสนใจที่สุดคือ ArgoCD v3.6.3/v3.5.9/v3.4.15 (24 พ.ย.) ซึ่งแก้ไข GitHub Security Advisory 4 รายการ (High/High/High/Moderate) แต่ ณ ขณะตรวจสอบยังไม่มีการกำหนดหมายเลข CVE อย่างเป็นทางการ จึงไม่ถูกนับเป็น "New CVE" ตามนโยบายของรายงานนี้ และ Pulumi v3.278.0 (24–25 พ.ย.) ที่มี Breaking Change ใน Go SDK (เปลี่ยน Return Type ของ property.Map.All/AllStable และ property.Array.All เป็น iter.Seq2, เปลี่ยนชื่อ property.Value.Secret เป็น IsSecret)

ด้าน Framework มี Angular 22.3.1 (Patch, 32 Bug Fix) และ Laravel 13.44.1 (Patch, ยืนยันได้เฉพาะ Version/วันที่จาก GitHub Tag เนื่องจาก laravel.com เข้าถึงไม่ได้ในรอบตรวจสอบนี้) ส่วน Vue 3.6 ยังไม่ GA โดยออก RC.17 (27 พ.ย.) ด้าน Programming Language มีเพียง Rust 1.100.1 (Patch แก้ Regression ของ Iterator Trait) ด้าน Operating System มีเพียงชุด Ubuntu Security Notice 10 รายการ (26 พ.ย.) ซึ่งเป็น Patch ระดับ Package (เช่น PyJWT, Guava, GNU binutils) ไม่ใช่ CVE ใหม่ของสัปดาห์นี้แต่เป็นการแพตช์ CVE ที่มีอยู่ก่อนแล้ว

ข้อจำกัดสำคัญของรอบตรวจสอบนี้: เว็บไซต์ Official หลายแห่งเข้าถึงไม่ได้โดยตรงจาก Network ของ Session นี้ด้วยสาเหตุ DNS/Network Policy (ไม่ใช่การบล็อกจากเว็บไซต์เอง) รวมถึง python.org, go.dev, github.blog, docs.docker.com, kubernetes.io, jenkins.io, docs.gitlab.com, laravel.com, redis.io, qemu.org, nginx.org, wireshark.org, debian.org, aws.amazon.com และ endoflife.date ทำให้หลายรายการต้องยืนยันผ่าน GitHub Releases (Official) โดยตรงเท่านั้นโดยไม่มีเนื้อหา Release Note ละเอียดประกอบ ดูรายการทั้งหมดใน UNCERTAIN ท้ายรายงาน
