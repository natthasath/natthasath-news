💻 Weekly Software Releases Report

Week: 37 Period: September 6 – 12, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (6–12 ก.ย. 2569) เป็นสัปดาห์ที่มีเหตุการณ์ด้านความปลอดภัยหนาแน่นที่สุดสัปดาห์หนึ่งของปี โดยมีช่องโหว่ระดับ CVSS 10.0 ใน GitLab (CVE-2026-85706) ที่เปิดให้ผู้โจมตีไม่ต้องยืนยันตัวตนอ่านไฟล์ใด ๆ บนเซิร์ฟเวอร์ได้ และถูกตรวจพบการโจมตีจริงตั้งแต่ 11 ก.ย. เพียงไม่กี่ชั่วโมงหลังประกาศ ตามมาด้วย Google Chrome 153 ที่แก้ไข Zero-day CVE-2026-87491 ใน V8 ที่ถูกใช้โจมตีจริง พร้อมเริ่มวงจร Release แบบ 2 สัปดาห์เป็นครั้งแรก

Microsoft Patch Tuesday เดือนกันยายนถือเป็นการอัปเดตครั้งใหญ่ที่สุดครั้งหนึ่งเท่าที่เคยมีมา (ตัวเลขรวมยังมีความคลาดเคลื่อนระหว่างแหล่งข่าว 964–1,169 CVE ขึ้นกับวิธีนับ) พร้อม Zero-day ที่ถูกโจมตีจริง 2 รายการ นอกจากนี้ยังมีการประสานแพตช์พร้อมกันของ Ubuntu, Debian, RHEL, Rocky Linux และ AlmaLinux สำหรับ Chromium, vim และ SPIP เมื่อ 12 ก.ย. ฝั่ง Programming Language มี Node.js ออกเวอร์ชันบำรุงรักษา 26.8.2 และ 24.21.0 LTS สัปดาห์นี้ไม่พบ Major Release หรือ Framework Release ใหม่ที่ตรวจสอบแหล่งที่มาได้ตามเกณฑ์ที่กำหนด

ประเด็นสำคัญ: ทีมงานที่ดูแล GitLab self-managed ควรอัปเกรดเป็น 19.3.2 / 19.2.6 / 19.1.8 โดยด่วนที่สุด เนื่องจากมีการโจมตีจริงแล้ว และควรเร่งอัปเดต Google Chrome รวมถึงแพ็กเกจ Chromium/vim บนระบบ Linux ที่ได้รับผลกระทบ
