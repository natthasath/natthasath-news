Weekly Digest — Week 35, 2026

💻 Weekly Software Releases Report — Week 35

Date: 27 Aug 2026 ช่วงเวลา: 20–27 Aug 2026 (ICT) Category: Software Source: Claude Code Routine

📌 Executive Summary

สัปดาห์นี้มี Major Release สำคัญคือ Kubernetes v1.37 "Garhwal" ที่เข้าสู่ GA อย่างเป็นทางการเมื่อ 26 Aug 2026 พร้อมการเลิกใช้ kube-dns แบบเก่า, IPVS mode และเดินหน้าถอด cgroup v1 ต่อเนื่อง ฝั่งภาษาโปรแกรมมิ่งมี Node.js v26.8.0 (Current) / v24.20.0 (LTS Krypton) และ Rust 1.98.0 ออกใหม่ ส่วน DevOps มี Terraform v1.16.0 และ GitLab 19.3.1 (Patch พร้อม Security Fix) ออกพร้อมกันในวันเดียวกัน (26 Aug)

ด้านความปลอดภัย สัปดาห์นี้ไม่มี Critical CVE ขนาดใหญ่แบบสัปดาห์ก่อน แต่มีความเคลื่อนไหวสำคัญจาก Ubuntu ที่ออก Patch แก้ CVE-2026-64531 ช่องโหว่ Local Privilege Escalation ผ่าน Open vSwitch บน Kernel 26.04 LTS และ CVE ใน FFmpeg (USN-8680-1) รวมถึง Debian ออก DSA สำหรับ OpenSSL (DSA-6465-1) และ Linux Kernel (DSA-6466-1) ในวันเดียวกัน (25 Aug) ฝั่ง GitLab พบช่องโหว่ระดับ Medium (CVSS 6.5) สองรายการที่แก้ไขในเวอร์ชัน Patch เดียวกัน

Elasticsearch 9.5.2 และ MariaDB 12.3.3 เป็น Maintenance Release ที่ออกในสัปดาห์นี้เช่นกัน ส่วน Spring Boot ออกพร้อมกันสามสาย (4.0.8 / 4.1.1 / 4.2.0-M1) และ VS Code อัปเดตเป็น 1.135

ไม่พบประกาศ End of Life ที่ยืนยันได้จากแหล่งข้อมูลทางการในช่วงสัปดาห์นี้ — มีข้อมูลจากแหล่งรอง (Tier 2/บทความ) กล่าวถึง Amazon Aurora MySQL v2 และ TrueNAS SCALE ว่าจะครบกำหนด EOL ในช่วงนี้ แต่เมื่อตรวจสอบกับเอกสารทางการของ AWS และ TrueNAS แล้วไม่พบวันที่ตรงกัน จึงไม่นำมาแสดงในรายงานนี้ (ดูหมายเหตุท้ายรายงาน)

สิ่งที่ต้องติดตามต่อคือ Oracle Java Critical Patch Update เดือนสิงหาคม (18 Aug, นอกช่วงรายงานนี้เล็กน้อย) ที่แก้ไข CVE จำนวนมาก และ Go 1.27 / Cisco Security Hardening Release ที่ออกก่อนช่วงรายงานหนึ่งวัน (19 Aug) ควรตรวจสอบผลกระทบต่อเนื่อง

⚠ Breaking Changes

SoftwareVersionBreaking ChangeMigration GuideSource
Kubernetes v1.37 ต้องใช้ containerd 2.0 ขึ้นไป, kubectl run --filename ถูก deprecate, Static Pods ไม่สามารถอ้างอิง Secrets หรือ ConfigMaps ได้อีกต่อไป, ipvs mode ใน kube-proxy เดินหน้า deprecate ต่อเนื่องหลาย release, cgroup v1 เดินหน้าสู่การถอดออกต่อเนื่อง มี Official Upgrade Notes — ควรตรวจสอบ containerd version และการใช้งาน Secrets/ConfigMaps ใน Static Pods ก่อนอัปเกรด kubernetes.io

ซอฟต์แวร์อื่นที่ Release ในสัปดาห์นี้ (Node.js, Rust, Spring Boot, Terraform, Elasticsearch, MariaDB, VS Code) ไม่มี Breaking Change ที่ระบุไว้อย่างชัดเจนใน Official Release Notes ของรอบนี้

👀 สิ่งที่ต้องติดตาม

  • Go 1.27 GA — ออกแล้วเมื่อ 19 Aug 2026 (หนึ่งวันก่อนช่วงรายงานนี้) เพิ่ม generic methods, encoding/json/v2, size-specialized memory allocation — ควรประเมินผลกระทบต่อ toolchain ในองค์กร
  • Oracle Java CSPU สิงหาคม 2026 — แก้ไข 925 CVE (943 patches) เมื่อ 18 Aug 2026 — Oracle เริ่มปรับเป็นรอบ Monthly Update ตั้งแต่รอบนี้ ควรวางแผน Patch Cycle ใหม่
  • Cisco Security Hardening Release (Crosswork / Secure Workload) — CVSS 10.0 ออกเมื่อ 19 Aug 2026 — ควรตรวจสอบว่าอุปกรณ์ในองค์กรได้รับผลกระทบหรือไม่
  • Redis 8.10.1 / 7.4.11 Security Release — ออกเมื่อ 17 Aug 2026 แก้ไข CVE-2026-62356 และช่องโหว่อื่น — ควรตรวจสอบว่าอัปเดตแล้วหากยังไม่ได้ดำเนินการ
  • PostgreSQL 18.6 / 17.11 / 16.15 / 15.19 / 14.24 — ออกเมื่อ 13 Aug 2026 แก้ไข 28 ช่องโหว่ — PostgreSQL 14 จะหยุดรับการแก้ไขตั้งแต่ 12 Nov 2026
  • Microsoft Patch Tuesday รอบถัดไป — คาดว่าจะออกประมาณสัปดาห์ที่สองของเดือนกันยายน 2026 (นอกช่วงรายงานนี้)
  • RHEL / Rocky Linux / AlmaLinux Errata — มี Errata ต่อเนื่องหลายรายการแต่ไม่สามารถยืนยันวันที่เจาะจงในสัปดาห์นี้ได้ ควรตรวจสอบ Errata Portal ของแต่ละ Distro โดยตรง
