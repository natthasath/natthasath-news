💻 Weekly Software Releases Report

Week: 45 Period: November 1 – 7, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (1–7 พ.ย. 2569) เป็นสัปดาห์ที่เงียบด้าน Major Release แต่มีความเคลื่อนไหวสำคัญด้านความปลอดภัยและ End of Life หลายรายการ โดยเหตุการณ์ที่กระทบผู้ใช้กว้างที่สุดคือ Google เปิดตัว Chrome 157 บน Stable Channel เมื่อ 3 พ.ย. 2569 (157.0.8103.38/.39) แก้ไขช่องโหว่ความปลอดภัยรวม 213 รายการ โดย 7 รายการจัดเป็น Critical (รวม CVE-2026-121156 และ CVE-2026-121247 ซึ่งเป็น Buffer Overflow ใน Dawn/WebGPU Engine) พร้อมอัปเดต Extended Stable เป็น 156.0.8078.88 (55 Security Fixes, 3 Critical) ในวันเดียวกัน — ข้อมูลนี้ยืนยันผ่าน WebSearch เนื่องจาก chromereleases.googleblog.com เข้าถึงไม่ได้โดยตรงในรอบตรวจสอบนี้

ด้าน Container Orchestration: Kubernetes เปิด Pre-release ตัวแรกของสาย 1.38 คือ v1.38.0-beta.0 เมื่อ 6 พ.ย. 2569 ตามกำหนดการพัฒนาปกติ ยังไม่ใช่ Stable และไม่พร้อมใช้งานจริง ด้าน End of Life มี 2 รายการที่ถึงกำหนดจริงในสัปดาห์นี้ ได้แก่ OpenSSL 3.6 (สาย Non-LTS) สิ้นสุดการสนับสนุนเมื่อ 1 พ.ย. 2569 และ Ruby on Rails 8.0.x สิ้นสุดการรับแพตช์ความปลอดภัยเมื่อ 7 พ.ย. 2569 (วันนี้) ตามประกาศทางการของทีม Rails เมื่อ 29 ต.ค. 2568

สำหรับ Programming Languages, Frameworks, Database, Operating System, Virtualization, Web Server และ Cloud Platform หลัก (Python, Go, Rust, PHP, Node.js, React, Django, PostgreSQL, MySQL, Redis, Ubuntu, RHEL, Debian, VMware, Nginx, Docker, GitLab, AWS/Azure/GCP) ไม่พบ Release หรือ Security Advisory ใหม่ที่ยืนยันวันที่แน่ชัดอยู่ในช่วง 1–7 พ.ย. 2569 จาก Official Source ที่เข้าถึงได้ในรอบตรวจสอบนี้ (ดูรายละเอียดในแต่ละหมวด)

ประเด็นสำคัญ: ทีมที่ใช้ Chrome/Chromium-based Browser ในองค์กรควรเร่งอัปเดตเป็น 157.0.8103.38+ โดยเร็วเนื่องจากมี Critical CVE หลายรายการ ทีมที่ใช้ OpenSSL 3.6 ควรวางแผนย้ายไปสาย 3.5 LTS (รองรับถึง เม.ย. 2573) หรือ 4.0 (รองรับถึง พ.ค. 2570) ทันทีเนื่องจากหมดการสนับสนุนแล้ว และทีมที่ใช้ Rails 8.0.x ควรอัปเกรดเป็น 8.1 (รับแพตช์ความปลอดภัยถึง ต.ค. 2570) เนื่องจากไม่มีแพตช์ความปลอดภัยใหม่อีกต่อไปนับจากวันนี้ นอกจากนี้ควรเตรียมตัวสำหรับวันที่ 10 พ.ย. 2569 ซึ่งเป็น Patch Tuesday และวันที่ .NET 8/.NET 9/PowerShell 7.4-7.5 จะครบกำหนด End of Life พร้อมกัน (ดู "สิ่งที่ต้องติดตาม")

👀 สิ่งที่ต้องติดตาม

  • Microsoft Patch Tuesday พฤศจิกายน 2569 — มีกำหนด 10 พ.ย. 2569 ยังไม่ประกาศรายละเอียด CVE ณ เวลาที่จัดทำรายงานนี้ (7 พ.ย. 2569)
  • .NET 8 / .NET 9 End of Life — มีกำหนด 10 พ.ย. 2569 (ตรงกับ Patch Tuesday) ทีมที่ยังใช้ .NET 8/9 ควรวางแผนอัปเกรดเป็น .NET 10 LTS โดยเร็ว
  • PowerShell 7.4 / 7.5 End of Life — มีกำหนด 10 พ.ย. 2569 เช่นเดียวกัน
  • PostgreSQL 19 Release Candidate 2 และ PostgreSQL 14 End of Life — ทั้งสองมีกำหนดวันที่ 12 พ.ย. 2569 ทีมที่ยังใช้ PostgreSQL 14 ควรวางแผนอัปเกรดเป็น 18 หรือรอ 19 ก่อนถึงกำหนด
  • PostgreSQL 19 GA — มีกำหนด 19 พ.ย. 2569 (อาจเลื่อนได้หากพบปัญหาใน RC2)
  • PHP 8.6.0 GA — มีกำหนด 19 พ.ย. 2569 ตาม Timetable ทางการ ยังมีความเสี่ยงเลื่อนหากพบ Blocking Bug ใน RC รอบสุดท้าย
  • Kubernetes v1.38.0 — อยู่ระหว่าง Beta (v1.38.0-beta.0 ออก 6 พ.ย. 2569) ควรติดตาม Release Note ฉบับสมบูรณ์เมื่อเข้าใกล้ GA

  • Microsoft Exchange Server 2016/2019 ESU — โปรแกรม Extended Security Update สิ้นสุดแล้วเมื่อ 31 ต.ค. 2569 (ก่อนช่วงเวลาของรายงานนี้ 1 วัน) และ Microsoft ยืนยันว่าจะไม่มี Period ถัดไป ทีมที่ยังใช้ Exchange 2016/2019 ควรเร่งย้ายไปเวอร์ชันที่รองรับ เนื่องจากจะไม่ได้รับแพตช์ความปลอดภัยอีกต่อไป
