💻 Weekly Software Releases Report

Week: 40 Period: September 27 – October 3, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (27 ก.ย. – 3 ต.ค. 2569) เป็นสัปดาห์ที่ไม่มี Major Release ใหม่ แต่มีประเด็นความปลอดภัยระดับ Critical ที่ "กำลังถูกโจมตีจริง" เป็นจุดเด่น ได้แก่ Citrix NetScaler ADC/Gateway ที่มีช่องโหว่ Critical 3 รายการ (CVE-2026-88771, CVE-2026-88772 คะแนน CVSSv4 9.5 ทั้งคู่ และ CVE-2026-88773 คะแนน 9.3) ซึ่ง 2 รายการแรกถูกเพิ่มเข้า CISA KEV Catalog ทันทีเนื่องจากพบการโจมตีจริง นอกจากนี้ Ubuntu ยังออกแพตช์ความปลอดภัยชุดใหญ่ (USN หลายรายการ) รวมถึงช่องโหว่ Critical ใน Authen::SASL::Perl (CVE-2026-86219, CVSS 9.8) และ OpenStack Designate (CVE-2026-71193, CVSS 9.6) ส่วน Docker Engine ก็ออกแพตช์ความปลอดภัย v29.8.2 แก้ไขช่องโหว่หลายรายการพร้อมกัน (CVE-2026-53493, CVE-2026-92543, CVE-2026-92542 และ BuildKit CVE อีก 10 รายการ)

ด้าน Software Release ทั่วไปเป็นสัปดาห์ที่สงบ: Rust ออก 1.99.0 (Minor) พร้อม Breaking Change เล็กน้อยด้าน Deprecation, Vue เข้าใกล้ GA ของเวอร์ชัน 3.6 มากขึ้นด้วย RC ตัวที่ 10 ที่โฟกัส Vapor Mode, Laravel ออก Framework 13.34.0, FastAPI เพิ่มการรองรับ OpenTelemetry แบบ Native ใน 0.142.0 และ Angular ออกแพตช์ 22.2.1 พร้อม Preview ของ 22.3 จากการตรวจสอบทั้ง 11 ระบบฐานข้อมูลหลัก ไม่พบ Release ที่ยืนยันได้ในสัปดาห์นี้ (PostgreSQL 19 GA ยังอยู่ระหว่างรอการยืนยันวันที่แน่ชัด) และไม่พบ Release ใหม่ของ Kubernetes, GitLab, ArgoCD หรือ Ansible เวอร์ชัน Stable

ประเด็นสำคัญ: ทีมที่ใช้งาน Citrix NetScaler ADC/Gateway ควรอัปเดตเป็น 14.1-73.37+ หรือ 13.1-64.23+ โดยเร่งด่วนที่สุดเนื่องจากมีการโจมตีจริงแล้ว ทีมที่ใช้ Docker Engine ควรอัปเกรดเป็น v29.8.2 (หรือ v25.0.18 สำหรับสาย Legacy) และทีมที่ใช้ Ubuntu LTS ควรตรวจสอบและติดตั้งแพตช์ USN ที่เกี่ยวข้องโดยเร็ว ส่วนทีมที่ใช้ Windows Server 2012/2012 R2 ควรเตรียมแผนย้ายระบบก่อนหมดระยะ ESU ในวันที่ 13 ต.ค. 2569 ซึ่งใกล้เข้ามาแล้ว
