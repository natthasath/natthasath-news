💻 Weekly Software Releases Report

Week: 44 Period: October 25 – 31, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (25–31 ต.ค. 2569) เงียบกว่าสัปดาห์ก่อนหน้าอย่างชัดเจน (ไม่มีเหตุการณ์ระดับ eMudhra CA/PHP2Shell) โดยเรื่องสำคัญที่สุดคือ Microsoft ออกแพตช์ .NET นอกรอบ (Out-of-band) เมื่อ 25 ต.ค. 2569 สำหรับ .NET 8.0.33 / 9.0.22 / 10.0.14 (GA) และ .NET 11.0 RC3 เพื่อแก้ไข CVE-2026-111497 (Brotli Decoder เขียนข้อมูลเกินขอบเขต) และ CVE-2026-114148 (สิทธิ์เจ้าของไฟล์ของ Tarball บน Linux) พร้อมออกแพตช์ซ้ำสำหรับ CVE-2026-70197 และ CVE-2026-102870 ที่แพตช์เมื่อ 13 ต.ค. 2569 แก้ไขไม่สมบูรณ์

ด้านอื่น Node.js เลื่อน v26.13.0 "Lithium" เข้าสู่ Active LTS อย่างเป็นทางการเมื่อ 28 ต.ค. 2569 พร้อม v24.22.2 "Krypton" (LTS Patch ปกติ ไม่มี CVE) และเปิด Alpha Channel แรกของ v27.0.0 ในวันถัดมา (29 ต.ค.) Kubernetes ออกชุด Patch Release พร้อมกันทุกสาย (v1.37.2, v1.36.6, v1.35.10, v1.34.13) และ Pre-release v1.38.0-alpha.3 ทั้งหมดเมื่อ 28 ต.ค. 2569 เช่นเดียวกับ Jenkins ที่ออก Weekly 2.588 และ LTS 2.580.2 ในวันเดียวกัน โดย LTS Changelog ร่างระบุว่ามี "การแก้ไขด้านความปลอดภัยหลายรายการ" แต่ไม่สามารถยืนยันหมายเลข CVE ได้โดยตรงจาก jenkins.io ในรอบตรวจสอบนี้

ด้าน Cloud: Google Cloud ทยอยปล่อย Google SecOps SOAR Release 6.3.104 ให้ภูมิภาคกลุ่มแรกเมื่อ 25 ต.ค. 2569 และ Azure SDK รอบเดือน ต.ค. 2569 มีรายงาน (ยังไม่ยืนยันกับ azure.github.io โดยตรง) ว่า Cosmos DB Client สำหรับ Rust เข้าสู่ GA (1.0.0) เป็นภาษาแรก ส่วน AWS Weekly Roundup ฉบับ 26 ต.ค. 2569 มีเพียงหัวข้อข่าวที่ดึงได้ (Amazon Polly Generative Engine, TorchNeuron สำหรับ Trainium) โดยไม่สามารถยืนยันรายละเอียดฉบับเต็มได้ในรอบตรวจสอบนี้

ประเด็นสำคัญ: ทีมที่ใช้ .NET ร่วมกับฟีเจอร์ Decompression (Request Decompression, HttpClient Response Decompression, System.IO.Compression Brotli API) ควรอัปเดตเป็น 8.0.33/9.0.22/10.0.14 โดยเร็ว และต้อง Rebuild/Republish Self-contained App หรือ Container Image ใหม่ เนื่องจาก Host Runtime ที่ใหม่กว่าไม่ได้อัปเดต Runtime ที่ Bundle มากับแอปโดยอัตโนมัติ ทีมที่ใช้ Jenkins LTS ควรตรวจสอบ Advisory ทางการที่ jenkins.io โดยตรงก่อนสรุปว่าไม่มีช่องโหว่ร้ายแรง เนื่องจากรายงานนี้ไม่สามารถยืนยันรายละเอียด CVE ของ 2.580.2 ได้ และทีมที่วางแผนอัปเกรด PostgreSQL ควรทราบว่า GA ของสาย 19 เลื่อนไปเป็น 19 พ.ย. 2569 (รายงานไปแล้วในสัปดาห์ก่อนหน้า) ไม่ใช่ปลาย ต.ค. ตามกำหนดเดิม
