💻 Weekly Software Releases Report

Week: 41 Period: October 4 – 10, 2026 Timezone: ICT (GMT+7)

📌 Executive Summary

สัปดาห์นี้ (4–10 ต.ค. 2569) ไม่มี Major Release ใหม่ แต่มีประเด็นความปลอดภัยที่ต้องเร่งติดตาม ได้แก่ Citrix NetScaler ADC/Gateway ที่พบช่องโหว่ High Severity ตัวใหม่ CVE-2026-88779 (CVSS 8.7) ซึ่งกำลังถูกโจมตีจริงและถูกเพิ่มเข้า CISA KEV Catalog เมื่อ 4 ต.ค. 2569 และ Django ออก Security Release พร้อมกัน 3 สาย (6.1.2 / 6.0.9 / 5.2.18) แก้ไข CVE ระดับ Medium 3-4 รายการ นอกจากนี้ Ubuntu ยังออก USN ชุดใหญ่ครอบคลุม Linux Kernel หลายสายและไลบรารีอย่าง BlueZ, libxml2, libgit2 และ libarchive

ด้าน Software Release ทั่วไป: Node.js ออก 26.11.0/26.11.1 (Current) เพิ่ม API ใหม่หลายรายการ, Laravel Framework v13.35.0, Angular แพตช์ 22.2.2, FastAPI ออก 0.143.0 ที่เปลี่ยน OpenTelemetry Auto-instrumentation เป็น Opt-in (Breaking Change), ArgoCD ออก Patch สายเสถียร v3.5.4/v3.4.10/v3.3.15 พร้อม RC ของ v3.6.0, Ansible Core แพตช์ 3 สาย (2.21.5/2.20.10/2.19.14), Elasticsearch ออก 9.5.5/9.4.8/8.19.23, Traefik Proxy ออกแพตช์ความปลอดภัย v3.7.14/v2.11.58 (รอ CVE ID จาก GHSA 8+5 รายการ) และ OpenVAS Scanner ออก v23.51.0 ที่มี Breaking Change สำคัญคือเขียน HTTP API ใหม่ทั้งหมดด้วย Axum ส่วน PHP เข้าสู่ Release Candidate รอบที่ 3 (8.6.0 RC3) และ Vue เข้าสู่ RC ตัวที่ 11 ของสาย 3.6

ประเด็นสำคัญ: ทีมที่ใช้งาน Citrix NetScaler ADC/Gateway ควรอัปเดตเป็น 14.1-73.41+ หรือ 13.1-64.28+ โดยเร่งด่วนเนื่องจากมีการโจมตีจริงแล้ว ทีมที่ใช้ Django ควรอัปเกรดเป็น 6.1.2/6.0.9/5.2.18 โดยเร็ว ทีมที่ใช้ Ubuntu LTS ควรตรวจสอบและติดตั้งแพตช์ USN ที่เกี่ยวข้อง และทีมที่ใช้ Windows Server 2012/2012 R2/2022 ควรเตรียมแผนรองรับ เนื่องจากระยะ ESU/Mainstream Support จะสิ้นสุดวันที่ 13 ต.ค. 2569 ซึ่งอยู่นอกกรอบ 7 วันของสัปดาห์นี้เพียง 3 วัน
