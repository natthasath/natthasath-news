1. Claude-BugHunter — ชุด Claude Code skill สำหรับ bug hunting/red-team

ปัญหา
ทีมรักษาความปลอดภัยต้องใช้เวลานานในการตั้งค่า workflow สำหรับสแกนและตรวจสอบช่องโหว่ซอฟต์แวร์ด้วยมือซ้ำ ๆ
วิธีใช้
ติดตั้งเป็นชุด skill ของ Claude Code ที่ผูก workflow bug hunting และ red-team ไว้ล่วงหน้า แล้วเรียกใช้งานผ่าน agent โดยตรง
ประโยชน์
ลดเวลาตั้งต้นของงาน bug hunting และทำให้กระบวนการตรวจสอบช่องโหว่ทำซ้ำได้อย่างมีโครงสร้าง

2. CLI-Anything — เปิดให้ AI agent ควบคุมซอฟต์แวร์ทุกชนิดผ่าน CLI

ปัญหา
ซอฟต์แวร์ส่วนใหญ่ไม่มี interface ที่ AI agent เรียกใช้ได้ตรง ต้องเขียน integration เฉพาะทางทุกครั้ง
วิธีใช้
ห่อ (wrap) ซอฟต์แวร์เดิมให้เรียกใช้งานผ่าน command line เดียวที่ agent เข้าใจ
ประโยชน์
ทำให้ AI agent ควบคุมซอฟต์แวร์เดิมที่มีอยู่แล้วได้ทันที โดยไม่ต้องพัฒนา integration ใหม่สำหรับแต่ละเครื่องมือ

3. last30days-skill — สรุปเทรนด์ข้ามแพลตฟอร์มด้วย AI agent

ปัญหา
การติดตามเทรนด์ล่าสุดต้องเปิดดูหลายแพลตฟอร์ม (Reddit, X, YouTube, Hacker News) แยกกันและสรุปด้วยมือ
วิธีใช้
ใช้เป็น AI agent skill ที่ค้นหาและสรุปหัวข้อที่กำหนดข้ามแพลตฟอร์มเหล่านี้ให้โดยอัตโนมัติ
ประโยชน์
ประหยัดเวลาในการทำ research เทรนด์ 30 วันล่าสุด และได้สรุปที่ครอบคลุมหลายแหล่งในที่เดียว
