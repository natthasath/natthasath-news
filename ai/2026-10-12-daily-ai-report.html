1. Reverse Engineering ซอฟต์แวร์ด้วย AI agent ผ่าน REA

ปัญหา
นักวิจัยความปลอดภัยและนักพัฒนามักต้องวิเคราะห์ไฟล์ไบนารีหรือแอปที่ไม่มีซอร์สโค้ด เช่น แอปเดสก์ท็อป, แอป Android หรือเฟิร์มแวร์ ซึ่งใช้เวลานานและต้องใช้ความเชี่ยวชาญเฉพาะทาง
วิธีใช้
ติดตั้ง REA เป็น MCP server ให้ AI agent วิเคราะห์ตั้งแต่พฤติกรรมแอประดับรันไทม์ไปจนถึง native binary โดยพึ่งพาเครื่องมือที่มีอยู่ เช่น Hopper, Ghidra หรือ IDA สำหรับการวิเคราะห์ไบนารีระดับลึก
ประโยชน์
ลดเวลาวิเคราะห์เบื้องต้นของซอฟต์แวร์ปิด พร้อมรายงานผลที่มีหลักฐานและข้อจำกัดประกอบ ช่วยให้ทั้งงานวิจัยความปลอดภัยและงานพัฒนาเข้าใจพฤติกรรมซอฟต์แวร์ได้เร็วขึ้น

2. จัดการ Context Window ของ Coding Agent ด้วย context-mode

ปัญหา
AI coding agent ที่ทำงานเป็นเวลานานมักเจอปัญหา context window เต็มจากผลลัพธ์ของ tool ที่สะสมมาก ทำให้ประสิทธิภาพลดลงหรือหลุดบริบทของงาน
วิธีใช้
ติดตั้ง context-mode เพื่อแยก (sandbox) ผลลัพธ์ของ tool ออกจาก context หลัก และคงความจำของ session ไว้ข้ามรอบการทำงาน
ประโยชน์
ช่วยให้ coding agent ทำงานยาวต่อเนื่องได้โดยไม่เปลืองพื้นที่ context เกินจำเป็น ลดค่าใช้จ่ายด้าน token และความเสี่ยงที่ agent จะหลุดบริบท
