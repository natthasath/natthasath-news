💡Use Cases

dream-num/univer — SDK สร้างเครื่องมือออฟฟิศที่ขับเคลื่อนด้วย AI

ปัญหา
นักพัฒนาที่ต้องการเพิ่มฟีเจอร์แก้ไขเอกสาร สเปรดชีต และการทำงานร่วมกันแบบเรียลไทม์ให้แอปพลิเคชันของตน มักต้องประกอบชิ้นส่วนจากหลายไลบรารีที่ไม่เชื่อมกันเป็นระบบเดียว
วิธีใช้
ใช้ Univer เป็น SDK กลางที่รวมการแก้ไข การคำนวณ การทำงานร่วมกัน และการประมวลผลไฟล์เอกสาร/สเปรดชีตไว้ในชุดเดียว พร้อมรองรับการต่อยอดด้วย AI agent
ประโยชน์
ทีมพัฒนาสร้างเครื่องมือออฟฟิศที่มี AI ช่วยงานได้เร็วขึ้นโดยไม่ต้องประกอบระบบเองจากศูนย์

NVIDIA/SkillEvaluator — ประเมินคุณภาพ AI agent skills อัตโนมัติ

ปัญหา
เมื่อมีการสร้าง agent skills/plugins จำนวนมากขึ้น ทีมพัฒนาขาดเครื่องมือกลางสำหรับตรวจสอบคุณภาพ ความซ้ำซ้อน และความปลอดภัยก่อนนำไปใช้งานจริง
วิธีใช้
รัน SkillEvaluator เพื่อตรวจสอบ skill/plugin ผ่าน quality gate ตรวจจับความซ้ำซ้อนของฟังก์ชัน และทดสอบกับ live agent จริงก่อนปล่อยใช้งาน
ประโยชน์
องค์กรลดความเสี่ยงจากการใช้ agent skills ที่มีคุณภาพต่ำหรือซ้ำซ้อนกัน และมีมาตรฐานกลางในการตรวจสอบก่อน deploy

google-research/paper-orchestra — เฟรมเวิร์กหลายเอเจนต์เขียนงานวิจัยอัตโนมัติ

ปัญหา
การเขียนงานวิจัยทางวิทยาศาสตร์ตั้งแต่ตั้งสมมติฐาน ทบทวนวรรณกรรม ไปจนถึงเรียบเรียงบทความ ใช้เวลาและแรงงานมนุษย์มาก
วิธีใช้
ใช้ paper-orchestra ประสานงาน AI agent หลายตัวให้ทำหน้าที่ต่างกันร่วมกัน เช่น ค้นคว้า วิเคราะห์ และเรียบเรียงเนื้อหางานวิจัย
ประโยชน์
นักวิจัยได้ร่างงานวิจัยเบื้องต้นเร็วขึ้น และสามารถโฟกัสเวลาไปที่การตรวจสอบและปรับปรุงเนื้อหาเชิงลึกแทน
