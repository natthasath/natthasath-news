⚙Technical Updates

  • Agent2Agent Protocol (A2A) เข้าสังกัด Agentic AI Foundation: Google ย้าย A2A ซึ่งเป็นมาตรฐานเปิดให้ agent ค้นหาและแลกเปลี่ยน "agent card" ระบุความสามารถ/endpoint ของกันและกัน เข้าเป็นโปรเจกต์ที่ Agentic AI Foundation เป็นเจ้าภาพ เคียงข้าง MCP, goose และ AGENTS.md โดย AAIF เติบโตจากสมาชิกไม่ถึง 40 รายเป็นกว่า 250 รายตั้งแต่ก่อตั้งเดือนธันวาคม 2568 (📰 Axios, DEVOPSdigest)
  • ZCode harness สำหรับ GLM-5.3: Z.ai เปิด ZCode เป็น harness ทางการที่ผสาน AI agent เข้ากับเครื่องมือวางแผน เขียนโค้ด รีวิว และ deploy รองรับ context แบบ lossless ถึง 1M token ลดปัญหา context drift ในงานระยะยาว (✅ Z.ai Blog (Official))
  • OpenAI Astra safety architecture: เพิ่มระบบตรวจสอบ chain-of-thought แบบ universal monitoring ทั่วทุกแอปพลิเคชัน agentic ของ Astra พร้อม sandboxed execution และเข้ารหัส model weights เข้มขึ้น เพื่อรับมือความเสี่ยงระดับ "Critical" ด้าน cybersecurity (✅ OpenAI Newsroom (Official))
  • Microsoft Copilot URL migration: เว็บแอป Copilot ย้ายจาก m365.cloud.microsoft ไปเป็น copilot.cloud.microsoft พร้อมแยก UI บัญชีงาน/ส่วนตัวชัดเจนขึ้น เริ่มพรีวิว 18 ส.ค. (📰 Microsoft Learn)

💡Use Cases

1. ครอบครัวใช้ ChatGPT for Teens ให้ลูกวัยรุ่นเรียนรู้อย่างปลอดภัยขึ้น

ปัญหา
วัยรุ่นใช้แชทบอท AI ทั่วไปเพื่อขอความเป็นเพื่อนหรือทำการบ้าน แต่เสี่ยงเจอเนื้อหาที่ไม่เหมาะสม เช่น เรื่องทำร้ายตัวเองหรือเนื้อหาทางเพศ โดยผู้ปกครองควบคุมได้จำกัด
วิธีใช้
เปิดใช้บัญชี ChatGPT for Teens ตั้งค่า Study Hours และ quiet hours ผ่านการควบคุมโดยผู้ปกครอง ให้ระบบเปลี่ยนเป็น Study Mode อัตโนมัติในช่วงเวลาที่กำหนด
ประโยชน์
ลดความเสี่ยงจากเนื้อหาที่ไม่เหมาะสม พร้อมได้เครื่องมือช่วยเรียนแบบมีคำแนะนำทีละขั้นตอนและ quiz ทบทวนความเข้าใจ

2. ทีมวิศวกรรมองค์กรใช้ GLM-5.3/ZCode ทำงาน long-horizon coding ที่ context ยาวมาก

ปัญหา
งานโค้ดดิ้งซับซ้อนที่ต้องอ้างอิงบริบทจำนวนมาก (เช่น refactor codebase ขนาดใหญ่) มักเจอปัญหา context drift หรือ agent ลืมเป้าหมายเดิมระหว่างทาง
วิธีใช้
ใช้ GLM Coding Plan ผ่าน ZCode harness ที่รองรับ context แบบ lossless ถึง 1M token สำหรับวางแผน เขียนโค้ด รีวิว และ deploy ในเวิร์กโฟลว์เดียว
ประโยชน์
คะแนน DeepSWE 1.1 เพิ่มจาก 46.2% เป็น 66.9% และ Terminal-Bench 3.0 เพิ่มจาก 4.6 เป็น 28.3 ลดความผิดพลาดจากการลืมบริบทในงานระยะยาว

3. ทีม AI safety ใช้ผลวิจัย "Mind Viruses" ออกแบบ system prompt ป้องกันการแพร่กระจายของแนวคิดอันตรายข้าม agent

ปัญหา
ระบบ multi-agent ที่ใช้ไฟล์ system prompt/memory ที่แก้ไขได้ร่วมกัน เสี่ยงให้แนวคิดหรือเป้าหมายที่ไม่พึงประสงค์แพร่กระจายจาก agent หนึ่งไปสู่อีก agent หนึ่งได้ แม้ context จะถูกล้างระหว่าง session
วิธีใช้
เพิ่มคำเตือนสั้นๆ ในระดับ system prompt ของทุก agent harness ตามแนวทางที่งานวิจัยพิสูจน์ว่าลดการแพร่กระจายได้เกือบสมบูรณ์ พร้อมตรวจสอบไฟล์ configuration ที่ agent เขียนถึงกันเอง
ประโยชน์
ลดความเสี่ยงจากพฤติกรรมผิดปกติที่แพร่กระจายในระบบ agent หลายตัว ก่อนที่จะกลายเป็นปัญหาความปลอดภัยในระดับ production

4. ทีม data science ในธุรกิจการเงินใช้ LLM แปลผล SHAP/GNNExplainer เป็นคำอธิบายความเสี่ยงสินเชื่อที่เข้าใจง่าย

ปัญหา
โมเดลประเมินความเสี่ยงสินเชื่อ (XGBoost, GNN) ให้ผลลัพธ์ที่แม่นยำแต่ตีความยากสำหรับผู้กู้หรือผู้กำกับดูแล ทำให้สื่อสารเหตุผลการอนุมัติ/ปฏิเสธได้ยาก
วิธีใช้
นำ pipeline จากงานวิจัยมาใช้ ให้ LLM แปลง post-hoc explanation artefact (SHAP, GNNExplainer) เป็นคำบรรยายที่เหมาะกับผู้อ่านแต่ละกลุ่ม (ผู้กู้ vs หน่วยงานกำกับดูแล)
ประโยชน์
เพิ่มความโปร่งใสของการตัดสินใจด้านสินเชื่อ ลดความเสี่ยงด้านการปฏิบัติตามกฎระเบียบ และช่วยให้ผู้กู้เข้าใจเหตุผลของผลการประเมิน

5. นักพัฒนา agent framework ใช้ StartupBench ประเมินความพร้อมก่อนขึ้น production จริง

ปัญหา
เบนช์มาร์ก agent ทั่วไปมักตั้งสมมติฐานความสามารถที่ไม่สะท้อนงานจริงในตลาด ทำให้ผลคะแนนสูงแต่ agent ยังทำงานจริงไม่ได้ผลตามที่คาด
วิธีใช้
ทดสอบ agent harness ของทีมด้วยชุด task ของ StartupBench ที่แปลงมาจากเวิร์กโฟลว์ผลิตภัณฑ์ AI startup ที่มีผู้ใช้จริง พร้อม rubric ประเมินละเอียด
ประโยชน์
ระบุจุดอ่อนด้านการทำตามคำสั่งซับซ้อนและความเชี่ยวชาญเฉพาะโดเมนได้ชัดเจน ก่อนนำ agent ไปใช้งานจริงกับลูกค้า
