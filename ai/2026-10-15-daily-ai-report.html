💡Use Cases

1. ลดค่าใช้จ่าย token ของ coding agent ด้วย Caveman

ปัญหา
การใช้ AI coding agent ต่อเนื่องเป็นเวลานานทำให้เกิดการใช้ token จำนวนมาก ส่งผลต่อค่าใช้จ่าย API และความเร็วในการตอบสนอง
วิธีใช้
ติดตั้ง Caveman เป็น skill และ proxy ให้กับ coding agent เพื่อบีบให้การตอบกลับของ agent สั้นกระชับแบบ "caveman-style"
ประโยชน์
ลดการใช้ token ลงประมาณ 65% ช่วยลดค่าใช้จ่ายและเพิ่มความเร็วของ agent โดยยังคงความสามารถในการทำงานหลัก

2. เพิ่มประสิทธิภาพและความปลอดภัยของ agent harness ด้วย ECC

ปัญหา
ทีมที่ใช้ AI coding agent หลายตัว (Claude Code, Codex, Cursor) มักต้องตั้งค่า skills, memory และมาตรการความปลอดภัยแยกกันในแต่ละเครื่องมือ ทำให้ขาดความสม่ำเสมอ
วิธีใช้
ติดตั้ง ECC เป็นระบบเพิ่มประสิทธิภาพกลางที่ครอบคลุม skills, memory และฟีเจอร์ความปลอดภัย ใช้ร่วมกับ agent harness ได้หลายตัว
ประโยชน์
ได้มาตรฐานประสิทธิภาพและความปลอดภัยที่สอดคล้องกันไม่ว่าจะใช้ agent harness ตัวใด ลดงานตั้งค่าซ้ำซ้อน

3. ค้นหาข้อมูลข้ามแหล่งให้ AI agent ด้วย xerj

ปัญหา
AI agent มักต้องดึงข้อมูลจากหลายแหล่งที่ต่างรูปแบบ เช่น โค้ด เอกสาร ล็อก และ PDF ซึ่งการค้นหาแบบกระจัดกระจายทำให้ผลลัพธ์ไม่แม่นยำ
วิธีใช้
ติดตั้ง xerj เป็นเสิร์ชเอนจินกลางที่ทำดัชนีโค้ด เอกสาร ล็อก และ PDF โดยอัตโนมัติ และเชื่อมต่อแบบเข้ากันได้กับ Elasticsearch
ประโยชน์
agent ค้นหาข้อมูลที่เกี่ยวข้องได้เร็วและแม่นยำขึ้น ลดความจำเป็นในการดูแลระบบค้นหาแยกหลายชุด

4. ค้นหาและติดตั้งปลั๊กอิน Claude Code ที่เชื่อถือได้ผ่าน claude-plugins-official

ปัญหา
นักพัฒนาที่ต้องการขยายความสามารถของ Claude Code ด้วยปลั๊กอินจากภายนอก มักขาดแหล่งรวมปลั๊กอินที่ผ่านการดูแลและตรวจสอบอย่างเป็นทางการ
วิธีใช้
เข้าถึงไดเรกทอรีปลั๊กอิน claude-plugins-official ที่ Anthropic ดูแลโดยตรง เพื่อเลือกและติดตั้งปลั๊กอินที่ต้องการ
ประโยชน์
ลดความเสี่ยงจากการติดตั้งปลั๊กอินที่ไม่ผ่านการตรวจสอบ และได้แหล่งอ้างอิงปลั๊กอินที่เป็นทางการจากผู้พัฒนา Claude Code เอง
