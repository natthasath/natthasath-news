⚙Technical Updates

Model Context Protocol (MCP) โพสต์ "A More Predictable Release Cycle for MCP" บน blog.modelcontextprotocol.io (เข้าถึงได้โดยตรงในรอบนี้) เมื่อ 11 พ.ย. 2569 ประกาศปรับจังหวะการออกสเปกเวอร์ชันใหม่ให้มีรอบที่คาดเดาได้มากขึ้น ✅ Official ก่อนหน้านี้ (10 พ.ย.) มีโพสต์ "Exploring File Uploads and Downloads in MCP" อธิบายแนวทางจัดการไฟล์อัปโหลด/ดาวน์โหลดในโปรโตคอล และ (30 ต.ค.) ประกาศ Ruby SDK สำหรับ MCP ขึ้นสู่ Tier 1 สเปกหลักของโปรโตคอลยังเป็นฉบับ 2026-07-28 ซึ่งเป็นสถานะต่อเนื่องจากรายงานฉบับก่อน ๆ ต่อเนื่อง

ไม่พบอัปเดต API/SDK/Framework ใหม่รายการอื่นที่ยืนยันแหล่งทางการได้ในรอบนี้ นอกเหนือจากโปรเจกต์โอเพนซอร์สด้าน agent/MCP ที่เข้าใหม่บน GitHub Trending วันนี้ (ดูหมวด Open Source) เช่น google-labs-code/stitch-skills และ cursor/plugins
