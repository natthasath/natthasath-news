Anthropic

1. Anthropic Cyber Mission — โครงการระยะยาวเพื่อช่วยผู้ป้องกันรักษาความปลอดภัยซอฟต์แวร์และระบบที่สังคมพึ่งพา เริ่มจาก 2 ด้าน: โครงสร้างพื้นฐานสำคัญ (critical infrastructure) และซอฟต์แวร์โอเพนซอร์ส ภายใต้ Critical Infrastructure Defense Program (CIDP) ที่นำโมเดล Claude รุ่นล่าสุด วิศวกรประจำที่ และงานวิจัยด้านภัยคุกคามไปช่วยผู้ให้บริการระบบ OT เช่น โครงข่ายไฟฟ้า ระบบน้ำ และระบบขนส่ง โดยมีพันธมิตรก่อตั้ง 11 แห่ง ได้แก่ Accenture, Booz Allen, CrowdStrike, Deloitte, Dragos, Hitachi, Insane Cyber, Nozomi Networks, Palo Alto Networks, PwC และ Rockwell Automation พร้อมเปิด OSS Scanner บริการสแกนความปลอดภัยฟรีสำหรับโปรเจกต์โอเพนซอร์ส (ดูหัวข้อ Tools & Apps) โครงการ Project Glasswing ถูกรวมเข้ากับ Cyber Verification Program ที่ขยายใหญ่ขึ้น และ Anthropic ยังสนับสนุนทุนให้ Python Software Foundation, Alpha-Omega, OpenSSF (ผ่าน Linux Foundation) และ Apache Software Foundation รวมถึงกองทุน Defender Advantage Fund (0xDAF) ที่เปิดตัวเดือนสิงหาคม Anthropic คาดการณ์ว่าภายใน ~2 ปี AI จะเอื้อประโยชน์ต่อฝ่ายป้องกันมากกว่าฝ่ายโจมตี ✅ Anthropic (official)

2. การอัปเดต Usage Policy ประจำปี 2569 — มีผลบังคับใช้ 12 พ.ย. 2569 สาระสำคัญ ได้แก่ รวมกฎเรื่องบัญชีปลอมและปฏิบัติการสร้างอิทธิพลไว้ในหมวดใหม่ "Do Not Engage in Deceptive Campaigns or Artificial Activity", ปรับหมวดการเลือกตั้งใหม่เป็น "Do Not Undermine Democratic Processes" โดยยกเลิกข้อห้ามเหมารวมเรื่องการกำหนดกลุ่มเป้าหมายผู้มีสิทธิเลือกตั้งที่ครอบคลุมงานเชิงประชาสังคมที่ชอบธรรมด้วย, ขยายข้อห้ามด้านอาวุธให้ครอบคลุมซอฟต์แวร์/ส่วนประกอบที่ทำให้อาวุธทำงานได้และการติดอาวุธให้โดรนหรือยานยนต์ไร้คนขับ, เขียนหมวดการเฝ้าระวังและการบังคับใช้กฎหมายใหม่ทั้งหมด (ห้ามติดตามบุคคลโดยไม่ได้รับความยินยอมและห้ามใช้ Claude ตัดสินใจเรื่องการสืบสวน/จับกุม/ฟ้องร้อง) และเพิ่มข้อกำหนดใหม่สำหรับ Claude ที่เชื่อมต่อฮาร์ดแวร์ที่ดำเนินการทางกายภาพได้เอง ✅ Anthropic (official)

3. คำมั่นสนับสนุน Genesis Mission — Anthropic ประกาศให้คำมั่นสนับสนุนเงิน 150 ล้านดอลลาร์ตลอด 3 ปี แก่ Genesis Mission ซึ่งเป็นโครงการระดับรัฐบาลกลางสหรัฐฯ ที่ใช้ AI เร่งการค้นพบทางวิทยาศาสตร์ โดยจะให้ Claude, Claude Code และเครดิต API แก่โครงการวิจัยหลายร้อยโครงการในกว่า 15 หน่วยงานที่เข้าร่วม Genesis Mission (รวมถึง NASA, NIH และ NSF) และร่วมมือกับห้องปฏิบัติการแห่งชาติในประเด็นเช่นพลังงานฟิวชันและคอมพิวเตอร์ควอนตัม ต่อเนื่องจากความร่วมมือกับกระทรวงพลังงานสหรัฐฯ (DOE) ตั้งแต่เดือนธันวาคม ประกาศนี้เผยแพร่ในงาน "Science: A New Golden Age" Summit ที่จัดโดยสำนักงานนโยบายวิทยาศาสตร์และเทคโนโลยีทำเนียบขาว ✅ Anthropic (official)

💡Use Cases

1. สแกนความปลอดภัยโอเพนซอร์สฟรีด้วย Anthropic OSS Scanner

ปัญหา
ผู้ดูแลโปรเจกต์โอเพนซอร์สจำนวนมากไม่มีทรัพยากรหรือความเชี่ยวชาญด้านความปลอดภัยเพียงพอที่จะตรวจหาและแก้ไขช่องโหว่อย่างสม่ำเสมอ ขณะที่การโจมตีช่องโหว่มีต้นทุนต่ำลงเรื่อย ๆ
วิธีใช้
ผู้ดูแลโปรเจกต์ลงทะเบียนแบบ opt-in เพื่อให้ OSS Scanner ของ Anthropic สแกนโค้ดด้วยโมเดล Claude รุ่นแข็งแรงที่สุดเป็นระยะ และรับรายงานที่มี proof of concept คำอธิบาย และข้อเสนอแนะการแก้ไข
ประโยชน์
Anthropic ระบุว่าอัตรา true-positive ของรายงานคาดว่าสูงกว่า 90% ช่วยให้โปรเจกต์โอเพนซอร์สขนาดเล็กเข้าถึงการตรวจสอบความปลอดภัยระดับสูงได้โดยไม่มีค่าใช้จ่าย

2. ป้องกันโครงสร้างพื้นฐานสำคัญด้วย Critical Infrastructure Defense Program

ปัญหา
ผู้ให้บริการระบบ OT เช่น โครงข่ายไฟฟ้า ระบบน้ำ และระบบขนส่ง เผชิญความเสี่ยงทางไซเบอร์ที่เพิ่มขึ้น ขณะที่การตรวจสอบและแก้ไขช่องโหว่ยังทำได้ช้า
วิธีใช้
ผู้ให้บริการที่เข้าร่วมโครงการนำร่องได้รับโมเดล Claude รุ่นล่าสุด วิศวกรประจำที่จาก Anthropic และงานวิจัยด้านภัยคุกคาม ร่วมกับพันธมิตรด้านความปลอดภัย 11 แห่ง เช่น CrowdStrike, Dragos และ Palo Alto Networks
ประโยชน์
Anthropic ระบุว่าพันธมิตรที่ใช้งานแล้วพบและแก้ไขช่องโหว่ได้จำนวนมาก และบริษัทคาดการณ์ว่าภายในราว 2 ปี AI จะเอื้อประโยชน์ต่อฝ่ายป้องกันมากกว่าฝ่ายโจมตี

3. ปรับแต่ง Claude ให้เชี่ยวชาญงานเฉพาะสายอาชีพด้วย knowledge-work-plugins

ปัญหา
การตั้งค่า Claude ให้เข้าใจบริบทงานเฉพาะด้าน เช่น sales, finance หรือ legal มักต้องใช้เวลาตั้งค่า prompt และเครื่องมือเชื่อมต่อเองตั้งแต่ต้น
วิธีใช้
ติดตั้งปลั๊กอินสำเร็จรูปจาก repo ของ Anthropic ผ่านคำสั่ง claude plugin marketplace add anthropics/knowledge-work-plugins แล้วเลือกปลั๊กอินที่ต้องการ เช่น claude plugin install sales@knowledge-work-plugins ซึ่งรวมสกิล คำสั่งลัด และการเชื่อมต่อ MCP ที่ปรับแต่งได้
ประโยชน์
ทีมงานได้จุดเริ่มต้นที่ปรับแต่งได้ทันทีโดยไม่ต้องสร้างโครงสร้างเองใหม่ทั้งหมด ลดเวลาตั้งค่า Claude สำหรับงาน knowledge work เฉพาะสายอาชีพ
