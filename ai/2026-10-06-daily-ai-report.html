Anthropic

Anthropic ประกาศขยายโครงการ Cyber Verification Program (CVP) เมื่อวันที่ 6 ต.ค. 2569 โดยรวมโครงการด้านความปลอดภัยไซเบอร์ก่อนหน้านี้เข้าเป็นโครงสร้างการเข้าถึง 3 ระดับ:

  • Defense Access — สำหรับงานป้องกันเชิงรับ (ตอบสนองเหตุการณ์ วิเคราะห์มัลแวร์ ตรวจสอบช่องโหว่) เปิดให้ทีมความปลอดภัยในองค์กร มหาวิทยาลัย หน่วยงานรัฐ ผู้ดูแลโอเพนซอร์ส และนักวิจัยอิสระ ใช้เวลาตรวจสอบคำขอไม่กี่วัน
  • Red Team Access — เพิ่มสิทธิ์การทดสอบเจาะระบบที่ได้รับอนุญาต สำหรับทีม red team ภายในองค์กรและหน่วยงานรัฐ ใช้เวลาตรวจสอบไม่กี่สัปดาห์
  • Specialized Access — ผ่อนปรนมากที่สุด จำกัดเฉพาะองค์กรที่ได้รับการยืนยันในการทดสอบระบบ safety-critical เช่น ระบบปฏิบัติการการบินและโครงข่ายไฟฟ้า ตรวจสอบร่วมกับรัฐบาลสหรัฐฯ

Anthropic เปิดเผยว่าพันธมิตรในโครงการ Project Glasswing พบช่องโหว่ซอฟต์แวร์ที่ยืนยันแล้ว 129,000 รายการ (เม.ย.–ก.ค. 2569) และทีมโอเพนซอร์สของ Anthropic เองพบเพิ่มอีก 5,500 รายการ (เม.ย.–ต.ค. 2569) รวมกว่า 134,500 รายการ โดยกว่า 33,000 รายการจัดอยู่ในระดับ critical หรือ high-severity พันธมิตรรายงานว่าโมเดลช่วยเร่งการค้นหาช่องโหว่ได้ "เร็วขึ้นเป็นเดือนหรือเป็นปี" โมเดลที่ใช้ในโครงการได้แก่ Claude Opus 5.5, Claude Sonnet 5.5 และ Claude Mythos 5.1 โดยมีพันธมิตรที่ระบุชื่อ เช่น Booz Allen และ Comcast ✅ Anthropic (official newsroom)

ทีมวิศวกรที่ใช้ coding agent หลายตัวต้องเขียนคำสั่ง/เวิร์กโฟลว์ซ้ำ ๆ (ตรวจสอบความเข้าใจงานก่อนเริ่ม, TDD loop, รีวิวโค้ด, ปรับสถาปัตยกรรม) โดยไม่มีมาตรฐานร่วม
วิธีใช้
ติดตั้งเป็น Claude Code plugin หรือผ่าน skills.sh แล้วเรียกใช้สกิลสำเร็จรูป เช่น /grill-me เพื่อให้ agent ซักถามความเข้าใจก่อนเริ่มงาน หรือ /improve-codebase-architecture เพื่อตรวจสถาปัตยกรรมโค้ด
ประโยชน์
ลดความแปรปรวนของคุณภาพงานที่ agent แต่ละครั้งผลิตออกมา และสร้างคำศัพท์ร่วม (GLOSSARY.md) ที่ลดความคลุมเครือในการสื่อสารกับ agent

3. เปิดสิทธิ์ AI ตามระดับความไว้วางใจให้ทีมความปลอดภัยไซเบอร์ (Anthropic Cyber Verification Program)

ปัญหา
งานป้องกันไซเบอร์เชิงรับ (ตรวจสอบช่องโหว่ วิเคราะห์มัลแวร์) มักมีลักษณะ dual-use ที่ทับซ้อนกับการใช้งานที่เป็นอันตราย ทำให้ safeguard มาตรฐานของโมเดล AI มักบล็อกงานที่ชอบด้วยกฎหมายไปด้วย
วิธีใช้
องค์กรสมัครเข้าโครงการตามระดับงาน (Defense / Red Team / Specialized) เพื่อรับสิทธิ์ใช้ Claude Opus 5.5, Sonnet 5.5 หรือ Mythos 5.1 โดยมี safeguard ที่ปรับให้เหมาะกับงานป้องกันมากขึ้น แต่ยังคงบล็อกการกระทำที่ก่อให้เกิดอันตรายทางกายภาพหรือความเสียหายขนาดใหญ่แบบ real-time
ประโยชน์
ช่วยให้ผู้ดูแลโครงสร้างพื้นฐานสำคัญ ผู้ดูแลโอเพนซอร์ส และนักวิจัยด้านความปลอดภัยใช้ศักยภาพเต็มของโมเดลในการค้นหาและแก้ช่องโหว่ได้เร็วขึ้น โดยมีหลักฐานจากพันธมิตรว่าพบช่องโหว่ยืนยันแล้วกว่า 134,500 รายการตั้งแต่เริ่มโครงการ
