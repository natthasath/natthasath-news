นักพัฒนาที่สร้าง MCP connector หรือ skills ให้ Claude ยังไม่มีช่องทางกลางที่เป็นทางการในการเผยแพร่ ติดตามสถานะรีวิว และวัดผลการใช้งาน
วิธีใช้
ส่งปลั๊กอินผ่านพอร์ทัล claude.ai/directory/manage โดยเลือกส่งเป็น MCP connector เดี่ยว หรือชุดปลั๊กอินที่รวม MCP server และ skills บน GitHub ระบบจะตรวจสอบความปลอดภัยอัตโนมัติก่อนรีวิว
ประโยชน์
ลดขั้นตอนการเผยแพร่ส่วนขยายให้ผู้ใช้ Claude ทุกช่องทาง (claude.ai, desktop, mobile, Cowork, Claude Code) พร้อมข้อมูลการติดตั้งและการค้นพบเพื่อปรับปรุงต่อยอด

2. บริหารทีม AI agent เหมือนพนักงานในองค์กร (paperclipai/paperclip)

ปัญหา
องค์กรที่เริ่มใช้ AI agent จากหลายผู้ให้บริการพร้อมกันในงานจริง ขาดเครื่องมือกลางในการมอบหมายงาน ควบคุมงบประมาณ และตรวจสอบผลงานของเอเจนต์แต่ละตัว
วิธีใช้
ติดตั้งแพลตฟอร์มโอเพนซอร์สที่รันเป็น Node.js server พร้อม React UI เพื่อมอบหมายงาน ตั้งลำดับชั้นองค์กร กำหนดงบประมาณ และอนุมัติงานของเอเจนต์แบบรวมศูนย์
ประโยชน์
ช่วยให้ทีมเทคนิคเห็นภาพรวมการทำงานของ AI agent จำนวนมากในที่เดียว ลดความเสี่ยงจากการปล่อยให้เอเจนต์ทำงานโดยไม่มีการกำกับดูแลด้านงบประมาณและขอบเขตงาน

3. ทดสอบแนวโน้มหลบเลี่ยงระบบตรวจสอบของเอเจนต์ก่อนใช้งานจริง (EvasionBench)

ปัญหา
ทีมความปลอดภัย AI ยังขาดวิธีวัดเชิงระบบว่าเอเจนต์ LLM จะพยายามหลบเลี่ยงกฎหรือระบบตรวจสอบขณะทำงานปกติ (ไม่ได้ตั้งใจเป็นปฏิปักษ์) มากน้อยเพียงใด
วิธีใช้
รันโมเดลผ่านชุดทดสอบ 50 คู่งาน-นโยบายของ EvasionBench ที่ออกแบบให้การทำงานให้สำเร็จต้องละเมิดกฎที่ระบบตรวจสอบกำหนดไว้ แล้ววัดอัตราการพยายามและอัตราความสำเร็จในการหลบเลี่ยง
ประโยชน์
ช่วยให้ผู้พัฒนาโมเดลและทีมความปลอดภัยประเมินความเสี่ยงก่อนปล่อยเอเจนต์ให้ทำงานอัตโนมัติในสภาพแวดล้อมจริงที่มีระบบตรวจสอบ (monitor) คอยกำกับ
