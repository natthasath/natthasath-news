💡Use Cases

1. ค้นหางานและเตรียมใบสมัครด้วย AI ที่รันในเครื่องผ่าน ai-job-search

ปัญหา
ผู้หางานต้องใช้เวลามากในการประเมินความเหมาะสมของตำแหน่งงาน ปรับ CV ให้ตรงกับแต่ละตำแหน่ง เขียน cover letter และเตรียมคำตอบสัมภาษณ์
วิธีใช้
ติดตั้ง MadsLorentzen/ai-job-search ซึ่งสร้างบน Claude Code เพื่อประเมินตำแหน่งงาน ปรับ CV อัตโนมัติ เขียน cover letter และช่วยเตรียมสัมภาษณ์ โดยรันทั้งหมดในเครื่องของผู้ใช้
ประโยชน์
ลดเวลาที่ใช้ในแต่ละใบสมัคร และเก็บข้อมูลส่วนตัวไว้ในเครื่องโดยไม่ต้องส่งออกไปยังบริการภายนอก

2. บริหารจัดการ fleet ของ coding agent หลายตัวด้วย orca

ปัญหา
ทีมพัฒนาที่ใช้ coding agent หลายตัวพร้อมกัน (เช่น Claude Code) มักขาดเครื่องมือกลางในการควบคุมและติดตามงานของ agent แต่ละตัว
วิธีใช้
ติดตั้ง stablyai/orca เพื่อบริหารจัดการ fleet ของ coding agent โดยใช้ subscription ที่มีอยู่แล้วของผู้ใช้เอง ไม่ต้องสมัครบริการเพิ่ม
ประโยชน์
ควบคุมและติดตามงานของ coding agent หลายตัวได้จากจุดเดียว ลดความซับซ้อนในการบริหารทีม agent ขนาดใหญ่

3. ส่งต่อความจำของ coding agent ข้ามผู้ให้บริการด้วย ai-memory

ปัญหา
นักพัฒนาที่สลับใช้ coding agent CLI จากผู้ให้บริการต่างกันมักสูญเสียบริบทและความจำระยะยาวของโครงการเมื่อเปลี่ยนเครื่องมือ
วิธีใช้
ติดตั้ง akitaonrails/ai-memory เป็นเลเยอร์ความจำระยะยาวกลางที่ coding agent CLI หลายตัวเรียกใช้ร่วมกันได้
ประโยชน์
คงบริบทและความจำของโครงการไว้ได้แม้เปลี่ยนผู้ให้บริการ agent ลดเวลาที่เสียไปกับการอธิบายบริบทซ้ำ

4. ทำให้ซอฟต์แวร์ agent-native ผ่าน CLI ด้วย CLI-Anything

ปัญหา
ซอฟต์แวร์จำนวนมากยังไม่มีอินเทอร์เฟซที่ agent เรียกใช้งานอัตโนมัติได้สะดวก ทำให้ต้องพึ่งการควบคุมผ่าน GUI ซึ่ง agent ใช้งานได้ยาก
วิธีใช้
ใช้ HKUDS/CLI-Anything เพื่อเปิดอินเทอร์เฟซแบบ command-line ให้ซอฟต์แวร์ที่ต้องการ ทำให้ agent เรียกใช้งานได้โดยตรง
ประโยชน์
ขยายความสามารถของ AI agent ให้ควบคุมซอฟต์แวร์ได้หลากหลายขึ้นโดยไม่ต้องพึ่งการจำลองการใช้งาน GUI
