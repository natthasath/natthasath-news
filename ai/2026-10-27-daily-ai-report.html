💡Use Cases

1. ป้องกัน "AI slop" ด้านการออกแบบในงาน coding agent (hallmark / impeccable)

ปัญหา
โค้ด UI ที่สร้างโดย AI coding agent มักมีหน้าตาซ้ำแบบเดิม ๆ ("AI slop") ขาดความประณีตด้านดีไซน์
วิธีใช้
ติดตั้ง skill อย่าง hallmark หรือภาษาการออกแบบ impeccable เข้ากับ Claude Code/Cursor/Codex เพื่อปรับแนวทางการออกแบบของ agent โดยอัตโนมัติ
ประโยชน์
ได้ผลลัพธ์ UI/ดีไซน์ที่ดูเป็นมืออาชีพมากขึ้นโดยไม่ต้องรีไรต์งานของ agent ด้วยมือ

2. ลดการใช้หน่วยความจำ/เพิ่มประสิทธิภาพของ agent harness (ECC)

ปัญหา
agent harness อย่าง Claude Code, Codex และ Cursor อาจใช้หน่วยความจำและทรัพยากรมากเกินจำเป็นเมื่อทำงาน session ยาว
วิธีใช้
ติดตั้งระบบโอเพนซอร์ส affaan-m/ECC เพื่อปรับประสิทธิภาพและหน่วยความจำของ harness เหล่านี้
ประโยชน์
ลดการใช้ทรัพยากรและเพิ่มความเสถียรของ session การทำงานกับ coding agent ที่ยาวนาน

3. ระบบติวเตอร์ AI ที่ปรับการสอนรายบุคคล (DeepTutor)

ปัญหา
การสอน/ติวแบบเดิมยากที่จะปรับให้เหมาะกับจังหวะการเรียนรู้ของผู้เรียนแต่ละคนอย่างต่อเนื่อง
วิธีใช้
ใช้เฟรมเวิร์กโอเพนซอร์ส HKUDS/DeepTutor ที่ติดตามและปรับเนื้อหาการสอนให้เหมาะกับผู้เรียนตามช่วงเวลา
ประโยชน์
เป็นฐานสำหรับทีมที่ต้องการสร้างระบบการเรียนรู้ส่วนบุคคลด้วย AI โดยไม่ต้องพัฒนาตั้งแต่ต้น

4. AI teammate ที่ทำงานต่อเนื่องแบบ local-first (openbot)

ปัญหา
การสั่งงาน agent หลายตัว (เช่น Codex, Claude, Grok) ให้ทำงานร่วมกันอย่างต่อเนื่องโดยไม่ต้องเปิดเทอร์มินัลค้างไว้ทำได้ยาก
วิธีใช้
ใช้แอป desktop โอเพนซอร์ส nightly-labs/openbot ซึ่งรัน agent หลายตัวพร้อม task queue และการทำงานร่วมกันระหว่าง agent แบบ local-first
ประโยชน์
จัดการ AI teammate หลายตัวให้ทำงานต่อเนื่องในเครื่องเดียวได้โดยไม่ต้องพึ่งพาบริการคลาวด์ภายนอก
