💡Use Cases

1. บีบอัดบริบทก่อนส่งถึง LLM ด้วย headroom

ปัญหา
ผลลัพธ์จาก tool, ล็อก, ไฟล์ และ RAG chunk จำนวนมากทำให้ context window ของ LLM เต็มเร็ว เพิ่มค่าใช้จ่ายด้าน token และลดคุณภาพคำตอบ
วิธีใช้
ติดตั้ง headroomlabs-ai/headroom เป็น library, proxy หรือ MCP server เพื่อบีบอัดข้อมูลเหล่านี้ก่อนส่งถึงโมเดล
ประโยชน์
ลดจำนวน token ที่ใช้ต่อการเรียกโมเดล ลดต้นทุน และช่วยให้ agent ทำงานกับบริบทขนาดใหญ่ได้มีประสิทธิภาพขึ้น

2. แปลงโค้ดเบสและเอกสารเป็น knowledge graph ด้วย graphify

ปัญหา
coding agent มักเข้าใจความสัมพันธ์ระหว่างไฟล์โค้ด เอกสาร สคีมา และคอนฟิกของโปรเจกต์ขนาดใหญ่ได้ไม่ครบถ้วนเมื่อค้นหาแบบ full-text
วิธีใช้
ติดตั้ง Graphify-Labs/graphify เพื่อแปลงโค้ดเบส เอกสาร สคีมา คอนฟิก และ PDF ของโปรเจกต์เป็น knowledge graph ที่สืบค้นได้ และเชื่อมต่อให้ Claude Code หรือเครื่องมืออื่นใช้งาน
ประโยชน์
ช่วยให้ agent เข้าใจความสัมพันธ์เชิงโครงสร้างของโปรเจกต์ได้แม่นยำขึ้น ลดการค้นหาที่ผิดพลาดหรือไม่ครบถ้วน

3. แปลงคำสั่งภาษาธรรมชาติเป็นการทำงานอัตโนมัติบน Android ด้วย artemis

ปัญหา
การทำงานอัตโนมัติบนแอป Android มักต้องเขียนสคริปต์เฉพาะเจาะจงกับแต่ละแอป ทำให้ AI coding assistant ควบคุมอุปกรณ์จริงได้ยาก
วิธีใช้
ใช้ google/artemis เพื่อแปลงคำสั่งภาษาธรรมชาติเป็นชุดการทำงานอัตโนมัติบน Android และเชื่อมต่อเข้ากับ AI coding assistant ที่มีอยู่
ประโยชน์
ลดเวลาเขียนสคริปต์ทดสอบหรือทำงานอัตโนมัติบนมือถือ และทำให้ agent ควบคุมแอป Android ได้โดยตรงจากคำสั่งภาษาธรรมชาติ

4. ทดสอบเจาะระบบแอปด้วย AI agent ผ่าน strix

ปัญหา
ทีมพัฒนาจำนวนมากไม่มีทรัพยากรหรือเวลาเพียงพอสำหรับทดสอบเจาะระบบ (penetration testing) อย่างสม่ำเสมอ ทำให้ช่องโหว่ด้านความปลอดภัยหลุดไปถึงโปรดักชัน
วิธีใช้
ติดตั้ง usestrix/strix ซึ่งเป็นเครื่องมือทดสอบเจาะระบบด้วย AI แบบโอเพนซอร์ส เพื่อค้นหาและช่วยแก้ช่องโหว่ของแอปโดยอัตโนมัติ
ประโยชน์
เพิ่มความถี่ในการตรวจสอบความปลอดภัยของแอปโดยไม่ต้องพึ่งทีม security ขนาดใหญ่ ช่วยลดความเสี่ยงที่ช่องโหว่จะถูกใช้โจมตีจริง
