⚙Technical Updates

  • MCP (Model Context Protocol) 2026-07-28: เปลี่ยนสถาปัตยกรรมหลักเป็นแบบไร้สถานะ (stateless) ตัด handshake initialize/Mcp-Session-Id ออก เพิ่ม Multi Round-Trip Requests (MRTR) ให้ tool ขอข้อมูลจากผู้ใช้กลางทางได้โดยไม่ต้องเปิด stream ค้างไว้ เพิ่ม header-based routing (Mcp-Method/Mcp-Name) ให้ gateway จัดเส้นทาง/นับปริมาณโดยไม่ต้องแกะ JSON body ผลลัพธ์แบบ list สามารถแคชได้ผ่าน ttlMs/cacheScope และยกระดับความปลอดภัยการยืนยันตัวตนด้วย RFC 9207 พร้อมเปลี่ยนจาก Dynamic Client Registration เป็น Client ID Metadata Documents — SDK ระดับ Tier 1 (TypeScript, Python, Go, C#) มียอดดาวน์โหลดรวมเกือบ 500 ล้านครั้งต่อเดือน โดย TypeScript และ Python ทะลุ 1 พันล้านดาวน์โหลดสะสมแล้ว — MCP Blog (Official)
  • NOOA (NVIDIA Labs Object-Oriented Agents): เฟรมเวิร์ก Python สำหรับสร้าง AI agent แบบ object-oriented — agent คือ object, method คือ action, field คือ state, docstring คือ prompt, type annotation คือ contract — ช่วยให้ harness ทดสอบ/ตรวจสอบย้อนกลับ/กำกับดูแลพฤติกรรม agent ได้ง่ายขึ้น (ดูหัวข้อ Open Source) — GitHub
  • MDASH: แพลตฟอร์ม agent ความปลอดภัยของ Microsoft ใช้ agent เฉพาะทางกว่า 100 ตัวทำงานร่วมกัน ตรวจโค้ด ถกเถียงความเป็นไปได้ของช่องโหว่ และสร้าง proof-of-concept ก่อนแจ้งนักพัฒนา (ดูหัวข้อ Tools & Apps) — The Register

💡Use Cases

1. MAI-Cyber-1-Flash + MDASH — ล่าช่องโหว่ในโปรเจกต์โอเพนซอร์สอัตโนมัติ

ปัญหา
ทีมความปลอดภัยมีโค้ดโอเพนซอร์สจำนวนมหาศาลต้องตรวจสอบ แต่การล่าช่องโหว่ด้วยแรงงานคนหรือเครื่องมือสแกนแบบเดิมทำได้ช้าและมีต้นทุนสูง
วิธีใช้
Microsoft ใช้โมเดล MAI-Cyber-1-Flash ร่วมกับแพลตฟอร์ม MDASH ที่มี agent เฉพาะทางกว่า 100 ตัวทำงานร่วมกัน ตรวจโค้ด ถกเถียงความเป็นไปได้ของช่องโหว่ และสร้าง proof-of-concept ยืนยันก่อนแจ้งนักพัฒนา โดยให้ AI รับภาระงานประจำวันราว 90% เหลือกรณีซับซ้อนให้โมเดลที่ใหญ่กว่าจัดการ
ประโยชน์
ลดต้นทุนการล่าช่องโหว่ลงราวครึ่งหนึ่งเทียบคู่แข่ง พร้อมความแม่นยำสูงตามผลทดสอบ CyberGym ที่ Microsoft รายงาน — MarkTechPost

2. NOOA — สร้าง AI agent ที่ทดสอบและตรวจสอบย้อนกลับได้

ปัญหา
องค์กรที่สร้าง AI agent มักขาดเครื่องมือมาตรฐานที่ทำให้ทดสอบ ตรวจสอบย้อนกลับ และกำกับดูแลพฤติกรรมของ agent ได้อย่างเป็นระบบ ทำให้ยากต่อการตรวจสอบความปลอดภัยก่อนใช้งานจริง
วิธีใช้
NVIDIA เปิดซอร์สเฟรมเวิร์ก NOOA ที่ออกแบบ agent เป็น Python object โดย method คือ action ที่โมเดลทำได้ field คือ state และ type annotation คือ contract ทำให้ harness ต่าง ๆ เชื่อมต่อและควบคุมพฤติกรรม agent ได้ง่ายขึ้น
ประโยชน์
ทีมพัฒนา agent ได้มาตรฐานเปิดสำหรับตรวจสอบ audit และกำกับดูแลความปลอดภัยของ agent อย่างเป็นระบบ ลดความเสี่ยงจากเหตุการณ์ agent หลุดควบคุมเช่นกรณี Hugging Face — GitHub

3. MCP 2026-07-28 (Stateless Core) — โครงสร้างพื้นฐาน AI agent ที่สเกลได้

ปัญหา
โปรโตคอล MCP แบบเดิมต้องรักษา session/stream ค้างไว้ระหว่าง client กับ server ทำให้ยากต่อการสเกลผ่าน gateway หรือ load balancer มาตรฐาน
วิธีใช้
สเปกใหม่เปลี่ยนแกนหลักเป็นแบบไร้สถานะ (stateless) ตัด session handshake ออก เพิ่ม header-based routing ให้ gateway จัดเส้นทางได้โดยไม่ต้องแกะ JSON body และรองรับผลลัพธ์แบบแคชได้
ประโยชน์
ผู้ให้บริการ MCP server ปรับสเกลระบบผ่านโครงสร้างพื้นฐานเว็บมาตรฐานได้ง่ายขึ้น ลดภาระการจัดการ session และเพิ่มความน่าเชื่อถือของระบบ agent ขนาดใหญ่ — MCP Blog
