แพลตฟอร์มที่สร้างผลิตภัณฑ์บน Claude API ให้ผู้ใช้ปลายทางหลายคนใช้งานร่วมกัน ต้องการระบุว่าการเรียก API แต่ละครั้งมาจากผู้ใช้รายใด เพื่อติดตามการใช้งาน การเรียกเก็บเงิน และการให้สิทธิ์ (trust grant) อย่างแม่นยำ
วิธีใช้
สร้างโปรไฟล์ผู้ใช้ผ่าน POST /v1/user_profiles พร้อมระบุ access_type ("application" สำหรับผู้ใช้ปลายทาง หรือ "passthrough" สำหรับองค์กรที่รับขายต่อ) แล้วส่ง ID โปรไฟล์ผ่าน header anthropic-user-profile-id ในคำขอ Messages, Message Batches หรือ token counting
ประโยชน์
แพลตฟอร์มติดตามการใช้งานและรายงาน analytics ระดับผู้ใช้ปลายทางได้แม่นยำขึ้น พร้อมเปิดทางให้ผู้ใช้ปลายทางลงทะเบียนรับ trust grant ของตนเองผ่าน enrollment URL

2. ตั้งค่า Auto Mode แบบมีไกด์ด้วย /auto-mode-setup (Claude Code)

ปัญหา
ผู้ใช้ Claude Code ที่ต้องการเปิดใช้ auto mode มักไม่แน่ใจว่าควรตั้งค่าสิทธิ์และโมเดลตัวจำแนก (classifier) อย่างไรให้เหมาะกับงานของตน
วิธีใช้
รันคำสั่ง /auto-mode-setup ใน Claude Code v2.1.304 ขึ้นไป เพื่อให้ระบบไกด์การตั้งค่า auto mode ทีละขั้นตอน พร้อมคำเตือนอัตโนมัติเมื่อ resume การสนทนาเก่าจะกินโควต้าเวลา 5 ชั่วโมงไปมาก
ประโยชน์
ลดความสับสนในการตั้งค่าสิทธิ์ของ agent ตั้งแต่แรก และช่วยผู้ใช้แพลน Pro/Max บริหารโควต้าการใช้งานได้ดีขึ้น

3. ตรวจสอบความปลอดภัยอัตโนมัติด้วย Coding Agent (cloudflare/security-audit-skill)

ปัญหา
การตรวจสอบความปลอดภัยของโค้ดด้วยมือใช้เวลานานและผลตรวจมักขาดความสอดคล้องกันระหว่างผู้ตรวจแต่ละคน
วิธีใช้
ติดตั้งสกิลนี้ให้กับ coding agent (เช่น Claude Code) เพื่อรันกระบวนการตรวจสอบความปลอดภัยแบบหลายขั้นตอนโดยอัตโนมัติ และได้ผลลัพธ์ที่ยืนยันได้และอ่านด้วยเครื่องได้
ประโยชน์
ทีมพัฒนาได้ผลตรวจความปลอดภัยที่สม่ำเสมอ ตรวจสอบย้อนกลับได้ และผนวกเข้ากับ pipeline อัตโนมัติได้ง่ายขึ้น

4. จัดการฝูง Coding Agent หลายตัวพร้อมกัน (stablyai/orca)

ปัญหา
นักพัฒนาที่ใช้ coding agent หลายตัว (เช่น Claude Code และ Codex) พร้อมกันในหลายงาน มักขาดเครื่องมือกลางสำหรับสั่งงานและมอนิเตอร์ทั้งหมดในที่เดียว
วิธีใช้
ติดตั้ง orca เพื่อรัน coding agent หลายตัวพร้อมกัน โดยแต่ละตัวทำงานใน git worktree ของตัวเอง แล้วมอนิเตอร์ความคืบหน้าผ่านแอปเดสก์ท็อปหรือมือถือ
ประโยชน์
เพิ่มปริมาณงานที่ทำได้พร้อมกันโดยไม่ชนกันระหว่าง agent และลดเวลาที่ต้องสลับหน้าต่างไปมาเพื่อติดตามงาน

5. ปรับ CV และเตรียมสัมภาษณ์งานอัตโนมัติด้วย AI (MadsLorentzen/ai-job-search)

ปัญหา
การหางานต้องปรับ CV และจดหมายสมัครงานให้เข้ากับประกาศงานแต่ละตำแหน่ง ซึ่งใช้เวลามากเมื่อสมัครหลายที่
วิธีใช้
ใช้เฟรมเวิร์กที่ต่อยอดจาก Claude Code เพื่อประเมินประกาศงาน ปรับ CV และจดหมายสมัครงานโดยอัตโนมัติ พร้อมช่วยเตรียมคำตอบสำหรับสัมภาษณ์ ทำงานในเครื่องผู้ใช้เองทั้งหมดโดยไม่ส่งข้อมูลขึ้นคลาวด์ส่วนกลาง
ประโยชน์
ลดเวลาที่ใช้ในการปรับเอกสารสมัครงานให้เข้ากับแต่ละตำแหน่ง และช่วยให้ผู้สมัครเตรียมตัวสัมภาษณ์ได้ดีขึ้น
