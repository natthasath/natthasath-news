⚙Technical Updates

Claude Code (CLI) ของ Anthropic อัปเดตจาก v2.1.318 เป็น v2.1.319 ในรอบนี้ (ยืนยันผ่าน npm registry dist-tags: latest = 2.1.319 และ CHANGELOG.md) ✅ Official จุดเปลี่ยนหลักได้แก่

  • Auto mode: เมื่อปิด telemetry หรือ feature flag (รวมถึงหลัง LLM gateway) การตรวจสอบที่เซิร์ฟเวอร์ไม่สามารถยืนยันได้จะกลายเป็นคำขอ prompt/deny แทนการ fallback ไปใช้ classifier ภายในตัว โดยมี environment variable สำหรับคืนค่าพฤติกรรมเดิมได้
  • MCP tasks: งานที่รันผ่าน MCP ในเทอร์มินัลจะถูกย้ายไปทำงานพื้นหลังทันที และ Claude จะได้รับแจ้งผลเมื่อเสร็จ มี variable ให้เลือกรอผลภายใน tool call แบบเดิมได้
  • Permissions: เพิ่ม setting permissions.denyInsteadOfPrompting เพื่อปฏิเสธคำขอ tool ที่ต้องรอการอนุมัติโดยอัตโนมัติ ทำให้ turn ดำเนินต่อได้โดยไม่ต้องหยุดรอ
  • คำสั่งใหม่: /claude-api latency-optimize สำหรับหาจุดที่โค้ด Claude API ทำงานช้า, /tasks สำหรับดู subagent ที่ทำงานเสร็จแล้วและเปิดกลับมาดูได้, /usage แสดงค่าใช้จ่ายสำหรับผู้ใช้ gateway บางราย
  • Claude apps gateway: เพิ่มตัวเลือก pooled group budget, การแจ้งเตือนก่อน login หมดอายุแบบเลือกได้, JSON log output และคำเตือนตอนเริ่มระบบเพิ่มเติม

ไม่สามารถเข้าถึง modelcontextprotocol.io ได้โดยตรงในรอบนี้ แต่ตรวจสอบผ่าน GitHub releases ของ modelcontextprotocol/modelcontextprotocol ได้ (เข้าถึงผ่าน github.com) พบว่าเวอร์ชัน stable ล่าสุดยังเป็นฉบับ 28 ก.ค. 2569 ไม่มีเวอร์ชันใหม่เผยแพร่ในรอบนี้ ต่อเนื่อง ไม่พบอัปเดต API/SDK/Framework ใหม่รายการอื่นที่ยืนยันแหล่งทางการได้ในรอบ 24 ชม. นี้

ข้อมูลจากรอบก่อนหน้า: การถอด fast mode ของ Opus 4.8 ยังมีกำหนดถอดออกจริงวันที่ 30 พ.ย. 2569 ตามเดิม (ดู Watch List) ต่อเนื่อง
