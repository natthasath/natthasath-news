1. ตรวจจับแรนซัมแวร์ด้วย multi-agent แบบคำนึงต้นทุน (SENTINEL/Cost-Aware Ransomware Detection)

ปัญหา
การตรวจจับและระบุตระกูลแรนซัมแวร์แบบเรียลไทม์ต้องแลกระหว่างความแม่นยำกับต้นทุนการประมวลผล โดยเฉพาะเมื่อสเกลขึ้นในสภาพแวดล้อมองค์กรขนาดใหญ่
วิธีใช้
ใช้สถาปัตยกรรม multi-agent แบบลำดับชั้นที่ปรับระดับการวิเคราะห์ตามความเสี่ยง มอบหมายงานเชิงลึกให้เฉพาะกรณีที่มีสัญญาณน่าสงสัยสูง
ประโยชน์
ลดต้นทุนการประมวลผลโดยรวม ขณะยังคงความสามารถระบุตระกูลมัลแวร์ได้แม่นยำ

2. ประเมินความเสี่ยงจากฟิชชิงที่สร้างด้วย LLM (Engineered Persuasion)

ปัญหา
องค์กรยังไม่มีข้อมูลเชิงปริมาณว่าการเจาะจงบุคคล (personalization) ในอีเมลฟิชชิงที่สร้างโดย LLM ส่งผลต่อโอกาสที่พนักงานจะหลงเชื่อมากน้อยเพียงใด
วิธีใช้
ทดลองกับพนักงานจริง 180 คน วัดความน่าเชื่อถือและความตั้งใจคลิกลิงก์ที่ระดับการเจาะจงข้อมูลต่างกัน 4 ระดับ
ประโยชน์
ให้ข้อมูลเชิงปริมาณ (เพิ่มโอกาสคลิก 28% ต่อระดับ) ที่ทีมความปลอดภัยสามารถใช้ออกแบบการอบรมตระหนักรู้ด้านฟิชชิงให้ตรงจุดมากขึ้น

3. สร้าง agent harness แบบปรับแต่งได้เต็มรูปแบบ (DeepSeek Harness)

ปัญหา
นักพัฒนาที่ต้องการปรับแต่ง agent runtime ระดับลึก (เช่น sandboxing, permission, telemetry) มักติดล็อกอยู่กับโครงสร้างปิดของผลิตภัณฑ์เชิงพาณิชย์
วิธีใช้
ใช้ DeepSeek Harness ซึ่งเปิดซอร์สภายใต้ MIT license โดยทุกองค์ประกอบ (model adapter, tool registry, session log, agent loop) เป็นปลั๊กอินที่แทนที่ได้อิสระ
ประโยชน์
นักพัฒนาปรับแต่งและควบคุม agent infrastructure ได้เองทั้งหมดโดยไม่ต้องพึ่งพาผลิตภัณฑ์ปิดของผู้ให้บริการรายใดรายหนึ่ง
