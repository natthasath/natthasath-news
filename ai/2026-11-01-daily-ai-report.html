⚙Technical Updates

Claude Code (CLI) v2.1.316 (เผยแพร่ 31 ต.ค. 2569) ✅ Official ยืนยันผ่าน npm registry และ CHANGELOG.md บน GitHub การเปลี่ยนแปลงหลักได้แก่:

  • เพิ่มตัวแปรสภาพแวดล้อม CLAUDE_CODE_DISABLE_ULTRATHINK สำหรับปิดคีย์เวิร์ด ultrathink
  • เพิ่ม pooled group budgets ให้ Claude apps gateway — งบประมาณรายเดือนที่สมาชิกกลุ่มใช้ร่วมกันเพิ่มเติมจากลิมิตส่วนตัว ตั้งค่าผ่าน pooled_budget ใน spend limits admin API
  • เพิ่ม CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP สำหรับเซิร์ฟเวอร์ที่ใช้ private CA แบบ cross-certificate วนกัน
  • เพิ่ม CLAUDE_CODE_SUBAGENT_EFFORT เพื่อกำหนด effort level ของ subagent เมื่อไม่ได้ระบุไว้ แทนการสืบทอดจากเซสชันหลัก
  • เพิ่ม managed.policy_mode: layered บน Claude apps gateway ให้ทุกนโยบายที่ตรงกับนักพัฒนามีผลพร้อมกัน แทนการใช้แค่นโยบายแรกที่ตรง
  • เพิ่ม guardrail.input_tagging สำหรับ Claude apps gateway บน Amazon Bedrock upstream เพื่อใส่แท็กที่ guardrail filter ของ Bedrock ต้องใช้
  • ⚠️ Deprecation เลิกใช้ fast mode บน Opus 4.8 ตั้งแต่ 30 ต.ค. 2569 และจะถอดออกจริง 30 พ.ย. 2569 หลังจากนั้นคำขอ fast mode บน Opus 4.8 จะคืน error ไม่ fallback ให้ย้ายไปใช้ Opus 5.5 แทน

ไม่พบการอัปเดต API/SDK/Framework/MCP อื่นที่ยืนยันแหล่งทางการได้ในรอบ 24 ชม. นี้ นอกเหนือจาก Claude Code CLI ข้างต้น
