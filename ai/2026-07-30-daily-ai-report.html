1. Claude Mythos Preview ค้นพบจุดอ่อนคริปโตที่ผู้เชี่ยวชาญมนุษย์มองข้าม 2 ปี

ปัญหา
ระบบเข้ารหัส HAWK (ผู้เข้าแข่งขันลายเซ็นดิจิทัลต้านควอนตัม) ผ่านการตรวจสอบโดยผู้เชี่ยวชาญมนุษย์ 2 รอบนานเกือบ 2 ปี แต่ยังมีจุดอ่อนเชิงโครงสร้างที่ไม่มีใครพบ ขณะที่การโจมตี AES แบบลดรอบด้วยวิธี meet-in-the-middle แบบเดิมยังมีขั้นตอนการเดาที่ไม่จำเป็น
วิธีใช้
นักวิจัยควบคุม Claude Mythos Preview ให้ทำงานวิจัยแบบกึ่งอัตโนมัติราว 60 ชั่วโมง จนพบความสมมาตรที่ไม่ธรรมดาในโครงสร้างแลตทิซของ HAWK และคิดค้นเทคนิค "Möbius Bridge" เพื่อตัดขั้นตอนการเดาออกจากการโจมตี AES
ประโยชน์
แสดงให้เห็นว่าโมเดล AI แนวหน้าสามารถทำงานวิจัยเข้ารหัสลับต้นฉบับได้ในระดับที่มนุษย์ผู้เชี่ยวชาญตรวจสอบมา 2 ปีไม่พบ ช่วยเสริมกระบวนการตรวจสอบความปลอดภัยของระบบเข้ารหัสก่อนนำไปใช้จริง — Anthropic

2. ChatGPT for Academic Researchers — เร่งงานวิจัยวิทยาศาสตร์ด้วยโมเดล frontier ฟรี

ปัญหา
นักวิจัยในสถาบันการศึกษาจำนวนมากไม่มีงบประมาณเข้าถึงโมเดล AI ระดับ frontier สำหรับงานวิจัยด้านวิทยาศาสตร์ คณิตศาสตร์ และวิศวกรรม
วิธีใช้
OpenAI มอบสิทธิ์เข้าถึง ChatGPT, ChatGPT Work และ Codex รวมถึง GPT-5.6 Sol Pro ฟรีให้นักวิจัยที่ผ่านการคัดเลือกจากสถาบันที่มีกิจกรรมวิจัยระดับสูง ครอบคลุมตั้งแต่การตั้งสมมติฐาน เขียนโค้ด จนถึงการเขียนขอทุนและตีพิมพ์ผลงาน
ประโยชน์
ขยายการเข้าถึงเครื่องมือ AI ขั้นสูงให้นักวิจัยตั้งแต่ 10,000 คนในระยะแรก ไปจนถึง 100,000 คนภายในปี 2570 ภายใต้งบสนับสนุนกว่า 250 ล้านดอลลาร์ — OpenAI

3. codebase-memory-mcp — ลด token ที่ AI coding agent ใช้อ่านโค้ดเบสซ้ำ

ปัญหา
AI coding agent มักต้องสแกนไฟล์ในโค้ดเบสขนาดใหญ่ซ้ำ ๆ เพื่อทำความเข้าใจโครงสร้างโปรเจกต์ ทำให้สิ้นเปลือง token และเวลาอย่างมาก
วิธีใช้
codebase-memory-mcp เป็น MCP server ที่จัดทำดัชนีโค้ดเบสเป็น persistent knowledge graph ด้วย tree-sitter และ SQLite ให้ agent เรียกดูโครงสร้างได้ทันทีโดยไม่ต้องสแกนไฟล์ใหม่ทุกครั้ง
ประโยชน์
ผู้พัฒนาระบุว่าลดการใช้ token สำหรับ query เชิงโครงสร้างได้สูงสุดถึง 99% ช่วยให้ AI coding agent ทำงานกับโค้ดเบสขนาดใหญ่ได้เร็วและประหยัดต้นทุนมากขึ้น — GitHub
