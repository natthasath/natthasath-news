ใช้ google/ax ซึ่งมีคำสั่งคล้าย kubectl (apply, get, describe, watch) เพื่อประกาศ, สั่งรัน และตรวจสอบสถานะ agent workload บน Agent Substrate
ประโยชน์
รองรับการรัน agent ระดับพันล้าน workload ต่อคลัสเตอร์ พร้อมการ suspend/resume แบบรวดเร็วเพื่อประหยัดทรัพยากรเมื่อ agent ไม่ได้ทำงาน

4. ควบคุมหุ่นยนต์อุตสาหกรรมข้ามฮาร์ดแวร์ด้วยเฟรมเวิร์กเปิด (Intrinsic Core)

ปัญหา
ผู้พัฒนาหุ่นยนต์อุตสาหกรรมมักต้องเขียนโค้ดควบคุม การหาตำแหน่งวัตถุ และวางแผนการเคลื่อนที่ใหม่ทุกครั้งที่เปลี่ยนฮาร์ดแวร์หรือผู้ผลิต
วิธีใช้
ใช้ Intrinsic Core ซึ่งเป็นชุดความสามารถแบบ ROS-compatible ที่รวม real-time control, pose estimation, motion planning และ grasp planning ไว้เป็นบล็อกสำเร็จรูป
ประโยชน์
ลดเวลาพัฒนาแอปพลิเคชันหุ่นยนต์ใหม่ เพราะใช้ความสามารถชุดเดียวกับที่ Intrinsic ใช้งานจริงในสายการผลิต และทำงานข้ามฮาร์ดแวร์ได้โดยไม่ต้องเขียนใหม่ทั้งหมด
