💡Use Cases

1. นักพัฒนาซอฟต์แวร์ใช้ Gemini 3.7 Flash ผ่าน Gemini Spark เพื่อ debug และส่งมอบโค้ด production-ready

ปัญหา
งาน debug และแก้ปัญหาโค้ดใช้เวลานาน ต้นทุน token ของโมเดลรุ่นก่อนสูง
วิธีใช้
ใช้ Gemini 3.7 Flash ผ่าน Gemini Spark สำหรับงาน debug และเขียนโค้ด deploy ได้ตั้งแต่ครั้งแรก
ประโยชน์
คะแนน DeepSWE v1.1 เพิ่มจาก 49.0% เป็น 65.3% ราคาลดลงครึ่งหนึ่งเทียบรุ่นก่อน

2. ทีมบริการลูกค้า/เสียง/ความปลอดภัยใช้ GPT-5.6 Sol โหมด Ultrafast สำหรับงานเรียลไทม์

ปัญหา
งานที่ต้องตอบสนองแบบเรียลไทม์ เช่น บริการเสียง งานการเงิน หรือการตอบสนองด้านความปลอดภัย ต้องการโมเดลที่เร็วโดยไม่ลดทอนความสามารถ
วิธีใช้
เรียกใช้ GPT-5.6 Sol ผ่านโหมด Ultrafast ที่ขับเคลื่อนด้วยโครงสร้างพื้นฐานของ Cerebras ผ่าน API
ประโยชน์
สร้างคำตอบได้เร็วขึ้นถึง 14 เท่า (750 token/วินาที) โดยคุณภาพเทียบเท่าโมเดลมาตรฐาน

3. องค์กรเลือก DeepSeek V4 Pro 0813 เป็นทางเลือกโมเดล agentic ต้นทุนต่ำ

ปัญหา
งาน agent/coding ขนาดใหญ่ต้องการโมเดลที่มีบริบทยาว (1M token) แต่ควบคุมต้นทุนให้ต่ำ
วิธีใช้
เชื่อมต่อ endpoint deepseek-v4-pro บน API ซึ่งอัปเดตเป็นบิลด์ 0813 แล้วโดยราคาคงเดิม
ประโยชน์
คะแนน Terminal-Bench 2.1 เพิ่มจาก 72.1 เป็น 87.9 และ DeepSWE จาก 12.8 เป็น 62.7 เทียบรุ่น Preview

4. ทีมพัฒนา agent ใช้ anthropics/skills ขยายความสามารถ Claude Code

ปัญหา
การสร้างความสามารถเฉพาะทาง (skills) ให้ agent ต้องเขียนโครงสร้างซ้ำๆ เอง
วิธีใช้
ใช้ repository ทางการ anthropics/skills เป็นแม่แบบ/คลังความสามารถสำหรับต่อยอด agent ของตนเอง
ประโยชน์
ลดเวลาพัฒนา ได้แนวทางที่ Anthropic รับรองและดูแลต่อเนื่อง (168,932 ดาว)

5. ผู้ผลิตอุปกรณ์ IoT/wearable ใช้ Needle 2 รัน agent บนอุปกรณ์ขนาดเล็ก

ปัญหา
อุปกรณ์ขนาดเล็ก (โทรศัพท์ราคาประหยัด, อุปกรณ์สวมใส่, ไมโครคอนโทรลเลอร์) มีหน่วยความจำและพลังประมวลผลจำกัด ไม่สามารถรันโมเดลภาษาขนาดใหญ่ได้
วิธีใช้
ฝังโมเดล Needle 2 ขนาด 14MB (45M พารามิเตอร์) ที่บีบอัดแบบ CQ2-bit ลงในอุปกรณ์เพื่อทำ tool calling และดึงข้อมูลแบบมีโครงสร้าง
ประโยชน์
ทำงานได้ถึง 500+ token/วินาทีบน Raspberry Pi 5 รันได้แม้บนไมโครคอนโทรลเลอร์อย่าง ESP32-S3
