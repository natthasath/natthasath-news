⚙Technical Updates

MCP (Model Context Protocol) — ต่อเนื่อง: สเปกฉบับ 2026-07-28 (ล่าสุด ยังเป็นเวอร์ชันที่นักพัฒนากำลังนำไปใช้งานอยู่ในปัจจุบัน) ปรับเป็น stateless core ตัดการใช้ Mcp-Session-Id เพิ่ม Multi Round-Trip Requests, การกำหนดเส้นทางผ่าน header, ผลลัพธ์ list ที่ cache ได้ และเสริมความแข็งแรงของ auth ให้สอดคล้อง OAuth/OIDC พร้อมส่วนขยาย MCP Apps (UI ที่เรนเดอร์จากฝั่งเซิร์ฟเวอร์) และ MCP Tasks (งานที่ใช้เวลานาน) ฟีเจอร์สเปกเดิมยังใช้งานได้อีกอย่างน้อย 12 เดือน

✅ Model Context Protocol Blog (Official)
