⚙Technical Updates

Claude Code (CLI) ออกเวอร์ชัน v2.1.318 (ยืนยันผ่าน npm registry และ CHANGELOG.md บน GitHub) ✅ Official สรุปการเปลี่ยนแปลงหลัก:

  • Gateway/AWS: รองรับ assume_role บน upstream ประเภท mantle ของ Claude apps gateway สำหรับ role ใน AWS account อื่นและการแยกค่าใช้จ่ายต่อนักพัฒนา
  • Mods: $.model.fork รับตัวเลือก effort ทำให้งานย่อยด่วนรันที่ effort ต่ำได้ และ Claude Code จดจำคำตอบเมื่อถามให้เปิดใช้ mod ที่เขียนในเซสชัน
  • Sign-in: claude auth status และ JSON output ของ claude -p แสดงวันหมดอายุของการล็อกอิน claude.ai ที่บันทึกไว้ พร้อมคำเตือนล่วงหน้า 10 วัน
  • Changes: ส่วนขยาย IDE จะไม่ถูกติดตั้ง/อัปเดตอีกเมื่อ Claude Code เริ่มทำงานใน IDE terminal และ background subagent จะย้ายคำสั่ง shell ที่รันนานไปทำงานเบื้องหลังหลัง 3 นาที
  • Cloud sessions: เพิ่มตัวเลือก "No repository" ให้เริ่มเซสชันบนสภาพแวดล้อมของ Anthropic ได้โดยไม่ต้องเลือก repository
  • Fixes: แก้บั๊กหลายรายการ รวมถึงประวัติการสนทนาหายหลังใช้ --continue, การกดปุ่มเผลอไปตอบ permission prompt, และการบันทึก config ล้มเหลวแบบเงียบบน network home directory

ข้อมูลจากรอบก่อนหน้า (v2.1.316): การถอด fast mode ของ Opus 4.8 ยังมีกำหนดถอดออกจริงวันที่ 30 พ.ย. 2569 ตามเดิม (ดู Watch List) ต่อเนื่อง
