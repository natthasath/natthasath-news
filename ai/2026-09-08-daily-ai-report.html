OpenAI

เกิดข้อพิพาทเรื่องเครดิตผลงานวิชาการ หลัง OpenAI ประกาศว่าโมเดลของบริษัทแก้โจทย์ปัญหา Navier-Stokes (ปัญหาคณิตศาสตร์ระดับรางวัล Millennium Prize) ได้สำเร็จ แต่ทริสตัน บั๊กมาสเตอร์ นักคณิตศาสตร์จาก NYU กล่าวหาว่า OpenAI ทราบความคืบหน้างานของเขาและเลเวนต์ อัลเปอเก (นักคณิตศาสตร์ของ Anthropic) ที่กำลังพิสูจน์ผล blow-up ของสมการออยเลอร์ (ก้าวสำคัญสู่ Navier-Stokes) มาก่อนที่ทั้งคู่จะเผยแพร่เอง และนำวิธีการเดียวกันไปใช้ นอกจากนี้ บั๊กมาสเตอร์ยังอ้างว่านักวิจัยของ OpenAI (Bubeck) พยายามขอให้ตัดชื่ออัลเปอเกออกจากเครดิต และตั้งคำถามว่า "ทำไมถึงอยากทำลายอาชีพตัวเอง" เมื่อบั๊กมาสเตอร์ต้องการเปิดเผยเรื่องนี้ต่อสาธารณะ OpenAI ตอบโต้ว่าทั้งนักวิจัยและเอเจนต์ของบริษัทไม่เคยเห็นงานของทั้งคู่ก่อนเผยแพร่ แต่ยอมรับว่าทั้งสองทีมทำงานในสายวิจัยที่เกี่ยวข้องกันจากงานฐานเดียวกัน 📰 TechCrunch · 📰 Axios · 📰 Scientific American

ในวันเดียวกัน OpenAI เปิดตัว ChatGPT Images 2.5 โมเดลสร้างภาพรุ่นใหม่ พร้อมโมเดล API สองตัวคือ GPT-Image-2.5 Flare และ GPT-Image-2.5 Sunburst (รายละเอียดในหัวข้อ AI Models และ Tools & Apps) ✅ OpenAI

ผู้บริโภคทั่วไปมีงานจุกจิกที่ต้องทำซ้ำ ๆ เช่น จองคิว จองตั๋ว ส่งอีเมล วางแผนกิจกรรมระยะยาว แต่ไม่มีเวลาหรือความสะดวกจัดการเอง
วิธีใช้
เชื่อมต่อ Muse กับอีเมล ปฏิทิน การชำระเงิน และบริการอื่น ๆ แล้วมอบหมายงานตั้งแต่ระดับง่าย (ส่งอีเมล) ไปจนถึงเป้าหมายระยะยาว (แผนออกกำลังกายรายปี) โดยระบบรันบน virtual machine เฉพาะของผู้ใช้แต่ละคน
ประโยชน์
ลดภาระงานจุกจิกประจำวัน พร้อมออกแบบให้แยกข้อมูลผู้ใช้แต่ละคนเพื่อลดความเสี่ยงด้านความเป็นส่วนตัว

2. สร้างภาพจากภาพร่างมือวาดด้วย Sketch (ChatGPT Images 2.5)

ปัญหา
ผู้ใช้ที่มีไอเดียภาพในหัวแต่บรรยายเป็นข้อความยาก มักได้ผลลัพธ์ที่ไม่ตรงกับที่จินตนาการไว้
วิธีใช้
วาดภาพร่างคร่าว ๆ ในแชทด้วยฟีเจอร์ Sketch (พิมพ์ "@Sketch") เพื่อใช้เป็นแนวทางโครงสร้างภาพ แล้วให้โมเดลเติมรายละเอียดและสไตล์ พร้อมเทมเพลตสำเร็จรูปสำหรับงานเฉพาะทาง เช่น โปสเตอร์และภาพสินค้า
ประโยชน์
ลดช่องว่างระหว่างไอเดียกับผลลัพธ์ ทำให้ควบคุมองค์ประกอบภาพได้แม่นยำขึ้นโดยไม่ต้องพึ่งพรอมป์ข้อความอย่างเดียว

3. เอเจนต์เขียนโค้ดระดับองค์กรที่สเกลรายได้เร็ว (Cognition Devin)

ปัญหา
ทีมวิศวกรรมซอฟต์แวร์ต้องการเพิ่มกำลังการพัฒนาโดยไม่เพิ่มจำนวนพนักงานตามสัดส่วน โดยเฉพาะงานที่ทำซ้ำได้และตรวจสอบได้
วิธีใช้
องค์กรนำเอเจนต์เขียนโค้ด Devin ของ Cognition ไปใช้งานจริงในสายการผลิตซอฟต์แวร์ สะท้อนจากอัตราการเติบโตรายได้ที่เกือบเพิ่มเป็นสองเท่าในเวลาไม่ถึง 4 เดือน
ประโยชน์
องค์กรขยายกำลังพัฒนาซอฟต์แวร์ได้เร็วขึ้นด้วยต้นทุนที่คาดการณ์ได้ สะท้อนจากเงินทุนและมูลค่าบริษัทที่นักลงทุนสถาบันให้ความเชื่อมั่น
