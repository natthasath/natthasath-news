💡Use Cases

Claude Fable 5.2 — ลดต้นทุนงาน coding เชิง agent ด้วยการเลือกระดับ effort

ปัญหา
ทีมพัฒนาที่ใช้โมเดล frontier สำหรับงาน coding เชิง agent ที่ซับซ้อนต้องแบกรับต้นทุนสูงเมื่อต้องใช้ระดับความสามารถสูงสุดอย่างต่อเนื่อง
วิธีใช้
Anthropic ระบุว่า Fable 5.2 ที่ระดับ effort "High" ทำคะแนนใกล้เคียงกับ Opus 5.5 ที่ระดับ "Max" บนเบนช์มาร์ก FrontierCode 2.0 ด้วยต้นทุนต่อการทำงานประมาณครึ่งเดียว
ประโยชน์
ทีมที่ปรับระดับ effort ให้เหมาะกับงานสามารถควบคุมต้นทุนได้ดีขึ้นโดยไม่เสียคุณภาพงานมากนัก

Claude Mythos 5.2 — ค้นหาช่องโหว่ความปลอดภัยสำหรับองค์กรที่ผ่านการตรวจสอบ

ปัญหา
ทีมวิจัยด้านความปลอดภัยไซเบอร์ต้องการโมเดลที่ไม่ถูกจำกัดด้วย safeguard ทั่วไปมากเกินไปในการช่วยค้นหาช่องโหว่ (vulnerability) อย่างมีประสิทธิภาพ
วิธีใช้
องค์กรที่ผ่าน Cyber Verification Program ของ Anthropic เข้าถึง Mythos 5.2 ซึ่งลด safeguard ด้าน cybersecurity ลง และตามการทดสอบภายในพบว่าค้นเจอช่องโหว่มากกว่า Opus 5.5 ถึง 10.2% บนชุดทดสอบ CVE Rediscovery
ประโยชน์
เร่งงานวิจัยด้าน offensive/defensive security ให้กับองค์กรที่ได้รับการตรวจสอบและควบคุมอย่างเหมาะสม

Claude Code v2.1.321 — context window 1M token เป็นค่า default

ปัญหา
งานที่ต้องอ่าน/แก้โค้ดในคลังขนาดใหญ่มักถูกจำกัดด้วย context window ที่เล็กเกินไปของโมเดล default เดิม
วิธีใช้
Claude Code อัปเดตให้ใช้ Fable 5.2 เป็นโมเดล default ซึ่งรองรับ context window ถึง 1,000,000 token
ประโยชน์
นักพัฒนาทำงานกับโค้ดเบสขนาดใหญ่หรือบทสนทนายาวต่อเนื่องได้โดยไม่ต้องตัด context ทิ้งบ่อยเท่าเดิม

Fable 5.2 แบบ multi-agent — ช่วยงานพิสูจน์ทางคณิตศาสตร์เชิงฟอร์มัล

ปัญหา
การแปลงบทพิสูจน์ทางคณิตศาสตร์ที่ซับซ้อนให้อยู่ในรูปแบบที่ตรวจสอบได้ด้วยเครื่อง (formal verification) ใช้เวลานานมากหากทำด้วยทีมมนุษย์หรือ agent เดี่ยว
วิธีใช้
Anthropic รายงานว่าใช้ Fable 5.2 ประสานงานกันราว 1,000 agent เพื่อแปลงทฤษฎีบทสุดท้ายของแฟร์มาต์ (Fermat's Last Theorem) ให้อยู่ในรูปแบบฟอร์มัลสำเร็จภายใน 30 ชั่วโมง
ประโยชน์
ลดเวลาจากที่ Anthropic เคยใช้ 11 วันในการฟอร์มัลไลซ์ครั้งแรก ลงมาเหลือเพียง 30 ชั่วโมง ชี้ให้เห็นศักยภาพของ agent หลายตัวทำงานพร้อมกันในงานวิจัยเชิงรูปแบบ
