📌 Executive Summary

สัปดาห์นี้แรงขับเคลื่อนหลักของวงการ Open Source อยู่ที่ระบบนิเวศ AI Agent และ MCP (Model Context Protocol) โดย PrimeIntellect-ai/prime-agent และ TencentCloud/TencentDB-Agent-Memory เติบโตแบบก้าวกระโดดหลายพันดาวในเจ็ดวัน สะท้อนความสนใจใน Agent ที่จดจำและปรับปรุงตัวเองได้ ฝั่งเครื่องมือพัฒนามีการออก Release สำคัญพร้อมกันจากหลายค่าย ทั้ง Ollama, Hugging Face Transformers, Next.js, Svelte และ Zed Editor ขณะที่ฝั่ง Cloud Native/Security มีข่าวใหญ่คือ Cloud Native Buildpacks graduate เป็นโครงการ CNCF เต็มตัว และ Kubernetes SIG ออก Kueue v0.19.1 ที่มาพร้อม Breaking Change ด้าน LeaderWorkerSet ที่ต้องระวัง โดยรวมแนวโน้มสัปดาห์นี้ชี้ว่าตลาดกำลังเปลี่ยนจาก "AI Assistant แบบเดี่ยว" ไปสู่ "Agent ที่ทำงานร่วมกันเป็นทีมและมีหน่วยความจำระยะยาว" อย่างชัดเจน

⚠️ Breaking Changes

kubernetes-sigs/kueue v0.19.1

ฟิลด์ spec.leaderWorkerTemplate.size ของ LeaderWorkerSet ที่จัดการโดย Kueue เปลี่ยนเป็น Immutable (เปิดใช้งานโดย Default ผ่าน Feature Gate LWSImmutableGroupSize) — Object เดิมที่ต้องการเปลี่ยนขนาดต้องสร้างใหม่ นอกจากนี้ Topology-Aware-Scheduling บังคับให้ต้องตั้งค่า podSetSliceSize เมื่อใช้ podSetSliceRequiredTopology — ต้องปรับ Manifest ก่อนอัปเกรด

MCP Spec — เปลี่ยนเป็น Stateless (28 ก.ค. 2026)

ข้อกำหนดของ Model Context Protocol เปลี่ยนไปเป็นแบบ Stateless ตั้งแต่ Release Candidate เมื่อ 28 ก.ค. 2026 ส่งผลต่อ MCP Server/Client ที่สร้างบน Transport แบบ Stateful เดิม — PrefectHQ/fastmcp v4.0.0b2 (7 ส.ค. 2026) เริ่มปรับตัวรองรับการเปลี่ยนแปลงนี้ในเวอร์ชันเบต้า ผู้ที่ใช้ FastMCP 3.x ควรอ่านคำแนะนำการย้ายก่อนอัปเกรด

ollama v0.32.10

เปลี่ยนค่า Default ของ repeat_penalty จาก 1.1 เป็น 1.0 ซึ่งเป็นการเปลี่ยนพฤติกรรม Sampling เริ่มต้น ผู้ที่ Pin ค่าพฤติกรรมเดิมไว้ควรตรวจสอบ Config
