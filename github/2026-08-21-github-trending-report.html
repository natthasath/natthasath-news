🔒 Security

⚠️ เรื่องใหญ่ที่สุดของสัปดาห์: เวิร์ม npm supply chain "ChainDrop / Shai-Hulud"
การโจมตีเริ่มตั้งแต่ 4 ส.ค. 2026 (ก่อนกรอบเจ็ดวันของรายงานนี้) แต่ยังลุกลามต่อเนื่องตลอดสัปดาห์นี้ ผู้โจมตีเข้าถึงบัญชี GitHub ของผู้ดูแล keyv แล้วใช้ GitHub Actions workflow เดิมปล่อยเวอร์ชันที่ถูกฝังโค้ดพร้อม provenance attestation ที่ถูกต้อง

ตัวเลขจากแหล่งต่าง ๆ ไม่ตรงกันและควรแสดงทั้งสองด้าน โดย SecurityWeek รายงานว่ามีเวอร์ชันอันตรายกว่า 2,200 รายการใน 440 package ขณะที่ หน่วยงาน CSA สิงคโปร์ ระบุตัวเลขที่ระดับ 1,300+ เวอร์ชันซึ่งคิดเป็นยอดดาวน์โหลดราวสองพันล้านครั้งต่อเดือน ความต่างนี้มาจากช่วงเวลาที่เก็บข้อมูลและนิยามการนับที่ต่างกัน เนื่องจากการโจมตียังดำเนินอยู่

  • วิธีแพร่กระจาย: ใช้ tarball ไม่ใช่ commit ทำให้การตรวจ source code ไม่พบอะไร โดยเมื่อได้ npm token จะดาวน์โหลด tarball ของทุก package ที่เข้าถึงได้แล้วประกอบใหม่พร้อม payload
  • สิ่งที่ขโมย: npm และ GitHub token, credential ของคลาวด์, SSH key, Kubernetes secret และ credential ฐานข้อมูล
  • การทำงาน: payload เป็น JavaScript ที่ทำ obfuscation หนักบนรันไทม์ Bun ทำงานผ่าน preinstall lifecycle hook และดึงโดเมนสำรองจาก Ethereum smart contract เพื่อหมุนโครงสร้างพื้นฐาน
  • สิ่งที่ควรทำ: ถือว่าเครื่องที่ติดตั้ง package ที่ได้รับผลกระทบถูกยึดครองแล้ว ให้หมุน credential จากเครื่องที่สะอาด อัปเดต npm CLI เป็น v11.10.0 ขึ้นไป เปิด min-release-age และตรวจไฟล์ .claude/settings.json กับ .vscode/tasks.json ที่ไม่ได้สร้างเอง ในทุก branch ทั้งนี้บน npm 12 ขึ้นไป preinstall hook ไม่ทำงานโดยค่าเริ่มต้น มัลแวร์จึงไม่ถูกรัน
