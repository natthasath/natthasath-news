⚠️ Breaking Changes

Effect-TS/effect v4.0.5 (effect package)
เผยแพร่ 15 ต.ค. 2026
  • Breaking: FileSystem.File.Info.dev เปลี่ยนเป็น bigint ส่วน ino, rdev, nlink และ blocks เปลี่ยนเป็น Option<bigint>
  • Breaking: Match.when, whenOr, whenAnd และ not จะปฏิเสธ object pattern ที่มี key ที่ input type ไม่มีอยู่จริง
  • Breaking: type ของ McpServer ต้องการ schema หรือ encoding service แล้ว หากไม่มีจะเกิด compile-time error
  • Breaking: ค่า redaction เริ่มต้นของ AWSAccessKeyId, Signature, sig และ X-Goog-Signature ย้ายไปอยู่ใน UrlParams ผู้ใช้ custom list ต้องปรับตาม
  • Breaking: ชื่อ span ของ entity RPC ใน effect และ @effect/cluster ไม่รวม entity ID อีกต่อไป
  • Requirement change: @effect/sql-sqlite-node v0.54.0 ต้องใช้ Node.js 22 ขึ้นไป
  • Migration: ทีมจัดทำรายงานไม่พบ migration guide ฉบับเต็มแยกต่างหากในรอบการค้นคว้านี้ รายละเอียดทั้งหมดอยู่ใน release notes ของแต่ละแพ็กเกจบนหน้า Releases เท่านั้น
  • ผลกระทบ: จำกัดเฉพาะผู้ใช้ฟีเจอร์ FileSystem metadata, Match pattern แบบ strict, MCP server integration และ AI tracing/redaction ของ Effect ผู้ใช้ core module ทั่วไปกระทบน้อย

สรุปแนวโน้ม Ecosystem

สัปดาห์นี้แกนกลางของ open source ecosystem ขยับเข้าสู่ "Agent Skills/Plugins" อย่างเต็มตัว โดยทั้งนักพัฒนารายบุคคล (mattpocock/skills, obra/superpowers) และบริษัทใหญ่ (Anthropic, Vercel, Cursor, Epic Games) ต่างสร้างระบบ skill/plugin ของตัวเองบนมาตรฐานเปิดที่ใกล้เคียงกัน สะท้อนว่า "Agent Skills" กำลังกลายเป็น primitive ใหม่ของการพัฒนาด้วย AI agent เช่นเดียวกับที่ package manager เคยเป็นสำหรับโค้ดทั่วไป ขณะเดียวกันหมวด "AI ช่วยงานความปลอดภัยเชิงรุก" ขยายจาก MCP เดี่ยวในสัปดาห์ก่อนสู่ pentesting agent แบบเต็มระบบผ่าน pentagi และ Pentest-Swarm-AI ซึ่งเป็นสัญญาณว่าแวดวง offensive security กำลังทดลองใช้ AI agent แบบอิสระมากขึ้น กรณีของ morluto/rea ที่ยอดดาวพุ่งขึ้นผิดปกติมากในสัปดาห์เดียวเป็นเครื่องเตือนว่าตัวเลข GitHub stars ไม่ควรถูกใช้เป็นตัวชี้วัดคุณภาพเพียงอย่างเดียวโดยไม่ตรวจสอบบริบท ฝั่งเฟรมเวิร์ก Effect-TS/effect ปล่อย breaking change ชุดใหญ่ที่นักพัฒนาควรตรวจสอบก่อนอัปเดต สัปดาห์ถัดไปควรจับตา 1) ว่ายอดดาวของ rea จะคงอยู่หรือลดลงอย่างมีนัยสำคัญ 2) ทิศทางของหมวด "pentesting agent" ที่เพิ่งเริ่มมีผู้เล่นชัดเจน และ 3) ว่าบริษัทใหญ่รายอื่น ๆ จะเปิดตัวระบบ agent skills ของตัวเองเพิ่มหรือไม่
