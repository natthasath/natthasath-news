📌 Executive Summary

สัปดาห์นี้หน้า GitHub Trending ถูกยึดครองโดยนิเวศ "Agent Skills" (ไฟล์ SKILL.md) อย่างท่วมท้น นำโดย cloudflare/security-audit-skill ที่ได้ดาวเพิ่ม 12,838 ดวงในสัปดาห์เดียว และ obra/superpowers ที่ทะลุ 309,000 ดาว พร้อมเครื่องมือสแกนความปลอดภัยของสกิลเกิดใหม่สองตัวพร้อมกัน (NVIDIA/SkillSpector และตัว security-audit-skill เอง) สะท้อนความกังวลเรื่อง supply chain ของสกิล AI agent ที่กำลังโตเร็วกว่าเครื่องมือตรวจสอบ ฝั่ง AI coding agent ยังแข่งกันดุเดือดต่อเนื่อง — Claude Code ปล่อย 5 เวอร์ชันในสัปดาห์นี้ (ล่าสุด v2.1.316) พร้อมประกาศเลิกใช้ Fast mode บน Opus 4.8 ภายใน 30 พ.ย., Gemini CLI ปล่อย v0.66.0 และ Cline ปรับ SDK จาก v0.0.95 กระโดดเป็น v0.2.0 พร้อมเปิดตัว Cloud Sessions เต็มรูปแบบ Kubernetes ปล่อย patch พร้อมกัน 4 สาย (v1.37.2/v1.36.6/v1.35.10/v1.34.13) ส่วนเหตุการณ์ที่น่าสังเกตคือ repository ที่เคยอยู่ภายใต้ sst/opencode ถูกย้ายไปอยู่ภายใต้องค์กร anomalyco โดยไม่มีคำประกาศที่ยืนยันได้ในรอบการค้นคว้านี้ และ multica-ai/andrej-karpathy-skills ที่มีอัตราส่วนดาว (227,000+) ต่อจำนวน commit (28 ครั้ง) สูงผิดปกติยังติด trending ต่อเนื่อง แม้เป็นโครงการที่เติบโตต่อเนื่องมาตั้งแต่กลางปีโดยไม่มีสัญญาณปั่นดาวใหม่ที่ยืนยันได้

ปล่อย patch พร้อมกัน 4 สายเวอร์ชันในวันเดียว อัปเกรด Go เป็น 1.26.10 แก้บั๊ก DRA taint eviction ที่ pod ใช้ extended resource แบบ DRA ไม่ถูก evict ตามที่ควร, แก้ Job reconciliation ที่ Job ใหม่สืบ pending expectation ของ Job เก่าที่ถูกลบไปแล้วแบบผิดพลาด, เพิ่มขีดจำกัด request header เป็น 16384 ค่า (ป้องกัน HTTP 431 กับผู้ใช้ที่มีกว่า 500 กลุ่ม) และแก้ regression ของ kube-proxy ที่พยายามตั้งค่า nf_conntrack_max โดยไม่มีสิทธิ์

anthropics/claude-code v2.1.316

anthropics/claude-code v2.1.314

Write, Edit และ NotebookEdit ถูกบล็อกไม่ให้แก้ไฟล์ที่อยู่นอก working directory ได้โดยอัตโนมัติ — เป็นการเสริมความปลอดภัยที่อาจกระทบ workflow ที่พึ่งพาการแก้ไฟล์นอก working directory โดยตรงมาก่อน

cline/cline SDK v0.2.0

SDK กระโดดจาก v0.0.95 เป็น v0.2.0 พร้อมเปลี่ยนพฤติกรรมให้ reattach เข้า live session แทนการแทนที่ runtime เดิม การเปลี่ยนเลขเวอร์ชันแบบกระโดดนี้มักสื่อถึง breaking API change แต่ทีมจัดทำรายงานไม่พบ migration guide โดยละเอียดในหน้า release ที่เข้าถึงได้ — ผู้ใช้ SDK ควรตรวจสอบ release note ฉบับเต็มก่อนอัปเกรด
