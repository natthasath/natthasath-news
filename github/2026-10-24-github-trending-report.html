📌 Executive Summary

สัปดาห์นี้เรื่องเด่นที่สุดไม่ใช่ repository เดียวแต่เป็นเหตุการณ์ด้านความปลอดภัยที่กระทบทั้ง ecosystem cloud-native: private key ของ intermediate CA 8 ตัวที่ดำเนินการโดย eMudhra รั่วไหล ทำให้ Mozilla, Google, Apple และ Microsoft ต้องบล็อก CA ดังกล่าวในเบราว์เซอร์/ระบบปฏิบัติการของตน และผลักให้โครงการ cloud-native ใหญ่อย่าง cilium, trivy, opentofu, argo-cd, cert-manager, prometheus และ moby ออก security patch ตอบสนองพร้อมกันในช่วง 20–23 ต.ค. ฝั่ง AI coding agent ยังแข่งกันดุเดือดต่อเนื่อง โดย Claude Code ปล่อย 10 เวอร์ชันในสัปดาห์เดียวรวมถึง v2.1.309 ที่แก้ช่องโหว่ sandbox escape ที่สำคัญ ขณะที่ Gemini CLI และ Cline ก็ปล่อยหลายเวอร์ชันเช่นกัน ด้าน AI/LLM infrastructure vllm ปล่อย v0.32.0 ที่ตัด Python 3.10 ออก และ duckdb ปล่อย major version 2.0 "Cyanoptera" โครงการ morluto/rea ยังติด Trending ต่อเนื่องจากสัปดาห์ก่อนแต่ยอดดาวที่ปรากฏ (~374,800 ★) ขัดแย้งกับจำนวน commit ที่มีเพียง 5,287 ครั้ง จึงควรตีความด้วยความระมัดระวังอย่างยิ่ง

🔒 Security

⚠️🔒 eMudhra Intermediate CA Compromise
เผยแพร่/ตอบสนอง 17–23 ต.ค. 2026 · ยืนยันจาก 5 แหล่งข่าวอิสระ

private key ของ intermediate CA จำนวน 8 ตัวที่ดำเนินการโดย eMudhra (ผู้ให้บริการ digital trust จากอินเดีย) ถูกคำนวณย้อนกลับได้ สาเหตุหลักมาจาก script ที่สร้าง key แบบ P-384 ผิดพลาดจนได้ key ที่อ่อนแอ Mozilla และ Google บล็อกใน Firefox/Chrome ตั้งแต่ 17 ต.ค. ตามด้วย Apple (19 ต.ค.) และ Microsoft (20 ต.ค.) เหตุการณ์นี้ส่งผลกระทบเป็นลูกโซ่ไปยังโครงการ cloud-native จำนวนมากที่ต้องปล่อย patch distrust CA นี้ในสัปดาห์เดียวกัน (ดูหมวด Cloud Native & DevOps: cilium, opentofu, argo-cd, cert-manager, prometheus, moby)

แหล่งอ้างอิง: The Hacker News, CSOonline, Dark Reading, SecurityWeek, InfoQ

ข้อมูลที่ขัดแย้งกันเล็กน้อย: บางแหล่ง (CSOonline) ระบุว่า Chrome ไม่จำเป็นต้องบล็อก certificate chain ที่ build ผ่าน intermediate ที่ถูกจำกัดไว้เฉพาะงาน code-signing เนื่องจาก TLS verifier ไม่ใช้ path นั้น ขณะที่ SecurityWeek เขียนว่าเบราว์เซอร์ "บล็อก" โดยรวม ความแตกต่างนี้น่าจะมาจากการอธิบายขอบเขตทางเทคนิคที่ต่างกัน ไม่ใช่ข้อมูลที่ขัดแย้งโดยตรง

สรุปแนวโน้ม Ecosystem

สัปดาห์นี้แสดงให้เห็นว่า open source ecosystem ไม่ได้ขับเคลื่อนด้วยกระแส "ฮิต" บน Trending เพียงอย่างเดียว แต่ยังเปราะบางต่อเหตุการณ์ด้าน supply-chain/PKI ระดับโครงสร้างพื้นฐาน เหตุการณ์ eMudhra CA compromise แสดงให้เห็นว่าโครงการ cloud-native ขนาดใหญ่ตั้งแต่ networking (cilium) ไปจนถึง GitOps (argo-cd) security scanning (trivy) และ container runtime (moby) ล้วนต้องพึ่งพา chain of trust เดียวกัน และต้องประสานการตอบสนองพร้อมกันเมื่อ CA ตัวใดตัวหนึ่งมีปัญหา ขณะเดียวกันการแข่งขันในหมวด AI coding agent ระหว่าง Anthropic (Claude Code), Google (Gemini CLI) และผู้เล่นโอเพนซอร์สอย่าง Cline และ opencode ยังดุเดือดต่อเนื่อง โดยความถี่ของ security/permission patch ใน Claude Code สัปดาห์นี้ชี้ให้เห็นว่าความปลอดภัยของ sandbox เป็นจุดที่ทุกผู้พัฒนา agent ต้องให้ความสำคัญมากขึ้น กรณีของ morluto/rea ที่ตัวเลขดาวขัดแย้งกับกิจกรรมจริงอย่างมากเป็นเครื่องเตือนซ้ำจากสัปดาห์ก่อนว่า GitHub stars ไม่ควรใช้เป็นตัวชี้วัดคุณภาพหรือความน่าเชื่อถือเพียงอย่างเดียว สัปดาห์ถัดไปควรจับตา 1) ผลกระทบระยะยาวของ eMudhra CA compromise ต่อ registry และ supply chain อื่น ๆ ที่ยังไม่ patch 2) migration guide ฉบับเต็มของ DuckDB 2.0 และ 3) ว่า MCP specification ฉบับใหม่ตาม roadmap เดือนสิงหาคมจะเริ่มปล่อยจริงเมื่อใด
