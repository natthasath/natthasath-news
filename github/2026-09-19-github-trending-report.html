🔒 Security

⚠️ CVE-2026-90999 — "Agentjacking" ใน Sentry Seer
เผยแพร่โดย CERT/CC เป็น VU#212479 เมื่อ 16 ก.ย. 2026 · ยังไม่มีแพตช์ ณ วันที่เผยแพร่

ช่องโหว่ trust-boundary แบบหลายขั้นตอนใน Sentry Seer เมื่อระบบถูกตั้งค่าให้ส่งต่อ issue ให้ coding agent แก้ไขอัตโนมัติ ผู้โจมตีภายนอกสามารถส่ง event ปลอมผ่าน public DSN โดยไม่ต้องมีสิทธิ์เข้าถึงบัญชี Sentry, repository หรือโครงสร้างพื้นฐานของเหยื่อเลย ข้อมูลที่ปลอมแปลงจะถูกฝังเข้าไปใน prompt ของ Seer และหลอกให้ coding agent ดาวน์โหลด/รันโค้ดที่ผู้โจมตีควบคุมภายในสภาพแวดล้อมที่มีสิทธิ์สูง นักวิจัยจาก Tenet Security เรียกรูปแบบการโจมตีนี้ว่า "agentjacking" คำแนะนำเบื้องต้นจาก CERT/CC คือปิดระบบส่งต่อแบบอัตโนมัติ จำกัดการติดตั้งแพ็กเกจของ coding agent หรือปิดการเชื่อมต่อ Seer ไปยัง agent ทั้งหมด

🧭 สรุปแนวโน้ม Open Source Ecosystem

หนึ่ง — "AI ผสาน deterministic engineering" กำลังเป็นทิศทางใหม่ของเครื่องมือ dev tools ตัวเลขดาวเพิ่มสูงสุดของสัปดาห์นี้ตกเป็นของ alibaba/open-code-review ซึ่งจงใจผสาน rule-based pipeline เข้ากับ LLM Agent แทนที่จะพึ่งพา LLM ล้วน สะท้อนว่าตลาดเริ่มมองหาเครื่องมือที่ให้ผลลัพธ์แม่นยำและตรวจสอบได้ มากกว่าความ "ฉลาดล้วน ๆ" ของ agent เพียงอย่างเดียว

สอง — โครงสร้างพื้นฐานสำหรับรัน agent อย่างปลอดภัย (agent sandboxing) กำลังเป็นรูปเป็นร่างจากหลายค่าย ทั้ง Kubernetes SIG (agent-sandbox), Tencent Cloud (CubeSandbox) และ Coder ต่างพัฒนาโซลูชันคู่ขนานสำหรับแยกสภาพแวดล้อมการทำงานของ AI agent ออกจากระบบหลัก ชี้ว่าอุตสาหกรรมเริ่มยอมรับว่าการให้ agent รันคำสั่งอัตโนมัติต้องมาพร้อมกับ isolation layer ที่เป็นมาตรฐาน

สาม — ช่องโหว่ "agentjacking" เป็นสัญญาณเตือนใหม่ของห่วงโซ่ความไว้วางใจใน AI agent กรณี CVE-2026-90999 ใน Sentry Seer แสดงให้เห็นรูปแบบการโจมตีที่ผู้โจมตีไม่จำเป็นต้องเข้าถึงระบบเป้าหมายเลย เพียงส่ง telemetry ปลอมผ่านช่องทางสาธารณะก็สามารถหลอกให้ agent รันโค้ดอันตรายในสภาพแวดล้อมที่มีสิทธิ์สูงได้ เป็นรูปแบบภัยคุกคามที่ต่างจากช่องโหว่ระดับ CLI/binary ทั่วไปที่เคยพบก่อนหน้านี้

สี่ — เครื่องมือ "เก่าแต่เชื่อถือได้" กลับมามีชีวิตใหม่ผ่าน MCP กรณีของ Ghidra (จาก NSA, เผยแพร่ปี 2019) ที่กลับมาติด Trending พร้อมกับ GhidraMCP แสดงให้เห็นว่าการเชื่อมเครื่องมือดั้งเดิมที่มีคุณภาพสูงเข้ากับ MCP สามารถปลุกความสนใจของชุมชนได้อีกครั้ง โดยไม่จำเป็นต้องสร้างเครื่องมือใหม่ทั้งหมด

เทคโนโลยีที่ควรจับตาในสัปดาห์หน้า ได้แก่ การออกแพตช์อย่างเป็นทางการสำหรับ CVE-2026-90999 จาก Sentry, อัตราการเติบโตต่อเนื่องของ alibaba/open-code-review ว่าจะยั่งยืนหรือชะลอตัวลงหลังจากพุ่งแรงในสัปดาห์แรก, ผลกระทบของ GitHub Copilot Model Deprecations รอบใหญ่ที่จะมีผล 2 ต.ค. 2026 ต่อทีมพัฒนาจำนวนมาก และพัฒนาการต่อเนื่องของโปรเจกต์ agent-sandbox ทั้งจากฝั่ง Kubernetes SIG และผู้ให้บริการ cloud รายใหญ่
