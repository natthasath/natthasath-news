⚠️ Breaking Changes

Effect-TS/effect v4.0.2 (effect package)
เผยแพร่ 7 ต.ค. 2026
  • Breaking: ลบ/เปลี่ยนชื่อ attribute ของ AI tracing — gen_ai.system ถูกแทนด้วย gen_ai.provider.name, ลบ BaseAttributes, WellKnownSystem, TokenAttributes, AllAttributes, option responseFormat ของ OpenAI และ WellKnownResponseFormat
  • Breaking: เปลี่ยนชื่อ span attribute concurrency, toolChoice, objectName เป็น effect.ai.concurrency, effect.ai.tool_choice, effect.ai.object_name และลบ response option cacheCreationInputTokens/cacheReadInputTokens ของ Anthropic
  • Behavior change: Config.orElse ไม่ recover mixed cause อีกต่อไป และ Effect.retry ไม่ retry failure ที่มี defect หรือ interruption
  • Migration: ทีมจัดทำรายงานไม่พบ migration guide ฉบับเต็มแยกต่างหากในรอบการค้นคว้านี้ รายละเอียดทั้งหมดอยู่ใน release notes ของแต่ละแพ็กเกจบนหน้า Releases เท่านั้น
  • ผลกระทบ: จำกัดเฉพาะผู้ใช้ฟีเจอร์ AI tracing/observability ของ Effect ผู้ใช้ core module ทั่วไปไม่กระทบโดยตรง
