📌 Executive Summary

ข้อจำกัดของข้อมูล: ไม่พบรายงานเหตุการณ์ด้าน supply-chain บน npm ครั้งใหม่ที่ยืนยันวันที่ตรงกรอบ 8–14 พ.ย. 2026 ได้โดยตรง (รายงานของ Sonatype ที่พบเกี่ยวกับ runtime loader บน npm ลงวันที่ 3 พ.ย. 2026 ซึ่งอยู่ก่อนกรอบสัปดาห์นี้) และไม่พบการอัปเดตสเปก MCP ฉบับใหม่ในกรอบนี้เช่นกัน (ฉบับล่าสุดที่ยืนยันได้คือ 2026-07-28) ส่วนหมวด Database ไม่พบ release หลักที่ยืนยันวันที่อยู่ในกรอบ 8–14 พ.ย. ได้แน่ชัด (ClickHouse 26.10 มีรายงานว่าออกในช่วง 2–8 พ.ย. ซึ่งคาบเกี่ยวกับขอบกรอบ จึงไม่นำมาแสดงในตาราง New Releases ของสัปดาห์นี้) UNCERTAIN: วันที่แน่นอนของ ClickHouse 26.10 release และวันที่แน่นอนของการประกาศดาวของ meta/astryx (หน้า GitHub ไม่แสดงวันที่เผยแพร่ repository หรือ release version ชัดเจน)

⚠️ anthropics/claude-code v2.1.325
13 พ.ย. 2026 · Security Fix + Permission Change

แก้ไขช่องโหว่ความปลอดภัยในวิธีถอดรหัสการตอบกลับที่บีบอัดด้วย zstd พร้อมปิดช่องว่างในการตรวจสิทธิ์ของ Bash — คำสั่งผสม (compound command) บางรูปแบบที่ก่อนหน้านี้ไม่ถูกถาม permission จะถูกถามแล้ว และ Bash allow rule จะไม่สามารถใช้รันโปรแกรมอื่นที่ไม่ตรงกับชื่อที่ระบุไว้ได้อีก ผู้ใช้ที่ตั้งค่า Bash allow rule แบบกว้างอาจพบว่าคำสั่งบางคำสั่งที่เคยรันได้อัตโนมัติจะถูกถามยืนยันหลังอัปเดต

สัปดาห์นี้ชี้ให้เห็นว่า "ความปลอดภัยของ agent skill" กำลังกลายเป็นหมวดย่อยใหม่ที่ชัดเจนขึ้นเรื่อย ๆ — ทั้ง Cloudflare (security-audit-skill) และ NVIDIA (SkillSpector) เปิดเครื่องมือตรวจสอบสกิลพร้อมกันในสัปดาห์เดียว หลังระบบ agent skill เติบโตเร็วจนความเสี่ยง supply-chain เริ่มเป็นที่จับตา ขณะเดียวกันบริษัทใหญ่ (Meta, Google, Vercel) ยังเปิดเครื่องมือภายในของตัวเองเป็นโอเพนซอร์สต่อเนื่อง สะท้อนว่าโครงสร้างพื้นฐานรอบ agent — ตั้งแต่ดีไซน์ซิสเทมที่ "agent ready" ไปจนถึง runtime และ sandbox สำหรับรัน agent — กำลังถูกสร้างขึ้นพร้อมกันจากหลายทิศทางโดยยังไม่มีมาตรฐานกลาง ที่น่าสนใจคือเครื่องมือ OSINT เก่าอย่าง sherlock กลับมาไวรัลแรงที่สุดในแง่ตัวเลข แสดงว่าความสนใจของ developer community ยังไม่ได้อยู่ที่ agent tooling เพียงอย่างเดียว สัปดาห์หน้าควรติดตามว่า Kubernetes v1.38.0 จะ stable เมื่อใด กำหนดถอด Fast mode บน Opus 4.8 ของ Claude Code (30 พ.ย.) จะกระทบผู้ใช้มากน้อยเพียงใด และจะมีเครื่องมือตรวจความปลอดภัยของ agent skill ตัวใหม่เพิ่มขึ้นอีกหรือไม่
