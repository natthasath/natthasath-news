⭐ Weekly GitHub Trending Open Source Report

ช่วงเวลา: 1 – 7 พ.ย. 2026 (ICT) หมวด: GitHub Open Source เผยแพร่: 7 พ.ย. 2026

📌 Executive Summary

สัปดาห์นี้หน้า GitHub Trending ยังถูกครองโดยเครื่องมือรอบ "AI coding agent" อย่างต่อเนื่อง นำโดย thedotmack/claude-mem ที่ให้ agent มีความจำข้ามเซสชัน (+8,726 ดาว) และ pingdotgg/t3code ที่เป็น "agent harness control surface" ควบคุม Claude Code/Codex/Cursor จากมือถือ/เว็บ/เดสก์ท็อป ซึ่งมีอัตราดาวเพิ่มสูงสุดของสัปดาห์ (+16,782 หรือ ~33% ของยอดรวม) ฝั่งบริษัทใหญ่ยังแข่งปล่อยเวอร์ชันต่อเนื่อง — Claude Code ปล่อย 4 เวอร์ชัน (v2.1.316–v2.1.319) พร้อมยืนยันการเลิกใช้ Fast mode บน Opus 4.8 ภายใน 30 พ.ย., Gemini CLI ปล่อย v0.67.0 stable และ OpenAI Codex ปล่อย v0.167.0 พร้อมฟีเจอร์ agent command center ส่วน Kubernetes ยังอยู่ในขั้น beta (v1.38.0-beta.0) ไม่มี patch ใหม่ในกรอบสัปดาห์นี้ ที่น่าสังเกตคือ NVIDIA/auto-ontology เติบโตแบบไวรัล (+8,035 ดาว จากฐาน ~1,400 ดาว หรือเพิ่มขึ้นกว่า 500%) ซึ่งเป็นอัตราเติบโตเชิงสัมพัทธ์สูงสุดของสัปดาห์ แม้ไม่มีรายงานเหตุการณ์ด้านความปลอดภัยขนาดใหญ่ใหม่ที่ยืนยันได้ในกรอบ 7 วันนี้

ข้อจำกัดของข้อมูล: ไม่พบรายงานเหตุการณ์ด้านความปลอดภัย (เช่น แคมเปญ supply-chain บน npm ครั้งใหม่) หรือการอัปเดตสเปก MCP ฉบับใหม่ ที่ยืนยันได้จากแหล่งข่าวว่าเกิดขึ้นในกรอบ 1–7 พ.ย. 2026 โดยเฉพาะในรอบการค้นคว้านี้ — ทีมจัดทำรายงานจึงไม่นำเหตุการณ์เก่ากว่ากรอบสัปดาห์มาแสดงเป็นข่าวใหม่ หน้า Hacker News แบบรายสัปดาห์ (community tier) ก็ไม่สามารถยืนยันรายการที่ตรงกรอบวันที่นี้ได้เช่นกัน จึงใช้ GitHub Trending/Releases เป็นหลักฐานหลักของรายงานฉบับนี้
